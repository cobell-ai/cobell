# Contributing

## Report a bug or suggest a change

Search [existing issues](https://github.com/cobell-ai/cobell/issues) before opening a new one. Reports may be written in your preferred language.

- For app bugs, include the app version, platform, steps to reproduce, and expected and actual results.
- For guide corrections, link the affected page and describe the current behavior.
- For feature requests, explain the task you want to accomplish and what currently prevents it.

Issues and pull requests are public. Remove credentials, account identifiers, personal information, and private conversation content from screenshots, examples, and logs.

## Edit the guides

Keep changes focused on the affected topic. Use English app labels and describe current public behavior in concise, factual language. Identify desktop, mobile, and CLI differences where relevant.

Follow the existing guide structure and update related index entries and links when adding, moving, or removing a page. App-guide links use the raw Markdown URLs so agents can follow them with HTTP GET requests. Check that each linked repository path exists.

Describe what you changed and how you checked it in the pull request. Contributions to this repository are provided under its [MIT License](LICENSE).
