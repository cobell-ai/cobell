## Reading this guide

- UI pages map screens and controls. Feature pages give complete task sequences. Related links connect both views and prerequisite tasks.
- Labels use the English app language. Explain in the user’s language; identify icons/nearby areas if their UI language differs. Mobile bottom-tab labels are hidden, so use position and icon.
- Only current public interfaces are covered. Device/tool availability can differ from an advertised catalog capability. Check ownership, account type, permissions and connection state when a control is absent.
- Saving a Gear does not verify its devices, Browser login or actual execution.
- Built-in tool instructions and input schemas are not published here.
