# Change your nickname: screen reference

Change the display name shown to other Cobell users.

## Open this screen

**Desktop:** Click your avatar/name near the upper-right of the main window. In User Info, click the pencil beside your current nickname.

**Mobile:** Tap the Home profile header or More profile card, then Account settings.

## Controls

| Control or area | Location and behavior |
|---|---|
| Desktop nickname pencil | Beside the name in User Info; opens Edit nickname. Also available in your own profile dialog. |
| Desktop Nickname | Prefilled text input in the dialog. |
| Desktop Cancel / Save | Bottom-right dialog actions; Cancel leaves the saved name unchanged. |
| Mobile Account settings | Button below the profile image on Profile. |
| Mobile Name | Editable field above Account details. |
| Mobile Save | Fixed button at the bottom of Account settings. |
| Mobile Back | Top-left arrow; dirty drafts open a Discard changes? confirmation. |
| Mobile profile image | Resolves a dirty nickname draft before opening image management. |
| Mobile Cancel / Discard | Keeps editing or abandons the nickname draft when leaving. |
| Mobile Retry | Reloads a failed profile read before editing is available. |

## Conditions and results

Names use 1–40 supported letters, digits or underscores, without spaces, and cannot be digits only. Leading/trailing whitespace is trimmed. Save is unavailable for an unchanged or invalid name and while saving. A failed update leaves the editor available for retry; mobile keeps the draft. Ordinary account editing requires your personal login.
