# Resolve owned chats before deleting an account: screen reference

Transfer each group’s representative role or close the group before continuing deletion.

## Open this screen

**Desktop:** Use the owned-room resolution dialog opened by Delete Account.

**Mobile:** Delete Account → Manage owned group chats.

## Controls

| Control or area | Location and behavior |
|---|---|
| Owned group chats list | Lists unresolved representative-owned groups. |
| Transfer ownership | Selects an eligible new representative. |
| Delete this chat | Closes the group for everyone. |
| Review changes / Confirm changes | Applies selected transfers and closures. |
| Refresh / Load more chats | Checks additional or changed ownership. |
| Continue account deletion | Rechecks deletion eligibility after ownership is resolved. |

## Conditions and results

These actions take effect immediately. Closing a group affects every participant. Cancelling account deletion does not reverse transfers or closures. If a result is uncertain, refresh ownership before choosing another action.
