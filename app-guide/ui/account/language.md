# Change the interface language: screen reference

Choose Cobell’s display language independently of message translation.

## Open this screen

**Desktop:** Click your avatar/name near the upper-right → Profile → Language, or Language on the login screen.

**Mobile:** Fifth bottom tab More → profile card → Language, or the globe on the login screen.

## Controls

| Control or area | Location and behavior |
|---|---|
| Language list | Choose the desired interface language. |
| Retry | Reloads failed settings. |
| Close / Back | Returns from the selector. |
| CLI /locale | Separately sets terminal language; app follows the desktop language. |

## CLI

Use `/locale` to open terminal language selection, `/locale LANGUAGE` to select one, or `/locale app` to follow the desktop language.

## Conditions and results

This changes UI labels; it does not translate chat messages. Use the chat Translate/Rewrite controls for message conversion. Terminal locale can differ from the app locale.
