# Change your profile image: screen reference

Choose a local image, generate an AI candidate, or remove your current avatar.

## Open this screen

**Desktop:** Click your top-right avatar/name, then the camera control on the profile image in User Info.

**Mobile:** Home profile header or More → Profile → Change Profile Image; also available in Account settings.

## Controls

| Control or area | Location and behavior |
|---|---|
| Choose image from device | Opens the device image picker. |
| Generate profile image with AI | Opens the generation request. |
| Reference image / art style / prompt | Optional guidance for an AI candidate. |
| Art style options | Automatic/skip style or Anime, Pixel Art, Realistic 3D, Cartoon, Watercolor and Line Art. The optional prompt accepts 80 characters. |
| Remove reference image | Clears the chosen generation input; does not delete the applied profile image. |
| Generate / Regenerate / Generate again | Starts or repeats generation. |
| Apply | Applies the reviewed candidate. |
| Mobile generation status card | Reopens progress/candidate details from Profile. Cancel stops generation, Retry repeats a failed request, Close dismisses a displayed failure and Discard removes an unaccepted candidate. |
| Desktop progress Close | Leaves the job running; reopen generation status from the profile image controls. |
| Delete profile image | Requires confirmation. |
| Cancel / Close / Discard | Leaves without applying a generated candidate. |

## Conditions and results

Generation and applying are separate actions. Mobile accepts nonempty JPEG, PNG or WebP files within 10 MiB for profile images and references. It reports permission, format, size and read errors. Image actions can be disabled during uploading or generation. Grant photo access when the picker requires it.
