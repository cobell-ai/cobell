# Change theme and app colors: screen reference

Set light/dark appearance and choose or customize a color theme.

## Open this screen

**Desktop:** Click your avatar/name near the upper-right → Profile → Theme.

**Mobile:** Fifth bottom tab More → profile card → Theme.

## Controls

| Control or area | Location and behavior |
|---|---|
| Light/Dark Mode | Select System, Light or Dark. |
| Theme Selection | Selects default or a supplied preset. |
| Mobile Custom / Customize Colors | Opens a draft for custom app, status, surface and chat colors. The current desktop theme screen does not expose this editor. |
| Mobile color row / picker | Chooses a color. Done applies it to the custom-theme draft; Cancel/Back leaves that color unchanged. |
| Mobile custom-theme Apply | Saves all chosen colors and activates the custom theme. |
| Mobile custom-theme Cancel / Back | A dirty draft asks whether to stay or discard. |
| Desktop Title Bar Style | Select system-default, Windows-style or Mac-style window controls. |
| Retry / Close / Back | Reloads failed theme settings or leaves the screen. |

## Conditions and results

Preset, brightness and desktop title-bar selections save immediately. A mobile custom color's Done applies only to the draft; the whole custom theme still needs Apply. Color groups cover primary/secondary/tertiary, error/error container, surface/variant/background, and chat background/own/person/DingDong bubbles. The picker does not expose transparency.

A failed mobile preset save restores the prior theme. A failed custom-theme save keeps the draft for retry. Mobile does not provide the desktop title-bar style control.
