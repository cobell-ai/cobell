# Change text size: screen reference

Adjust personal display sizes on this device.

## Open this screen

**Desktop:** Upper-right avatar/name → Profile → Text size.

**Mobile:** Home profile header or More → Profile → Text size.

## Controls

| Control or area | Behavior |
|---|---|
| Desktop Chat text size | Sets chat text from 90% to 160%, in 10-point steps. |
| Mobile App text size | Sets general app text from 90% to 160%. |
| Mobile Chat follows app size | Uses the app size for chat text. Turning it off exposes a separate Chat text size slider. |
| Mobile Chat text size | Sets a separate 90%–160% chat size when follow-app is off. |
| Also scale chat input | Uses the chat size for message inputs. When off, desktop inputs stay at their standard size and mobile inputs follow app size. |
| Preview | Shows sample message, code, timestamp and input text; it does not send a message. |
| Reset | Restores 100% defaults, input scaling on and mobile chat following app size. |
| Retry | Retries a failed settings load. |
| Close / Back | Leaves text-size settings. |

## Conditions and results

Slider dragging previews the selected size; releasing it saves. Switches and Reset save without a separate final Save button. Failed persistence returns to committed settings and displays an error. These preferences belong to the current user on this device and apply across rooms.

Lists try to keep the current message visible when text size changes. The visible position can shift as text reflows; scroll to the message you need.
