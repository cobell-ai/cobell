# Request account deletion: screen reference

Review prerequisites, verify your account and explicitly request deletion.

## Open this screen

**Desktop:** Click your avatar/name near the upper-right → Profile → Delete Account.

**Mobile:** Fifth bottom tab More → profile card → Delete Account.

## Controls

| Control or area | Location and behavior |
|---|---|
| Eligibility check | Reports active subscriptions, pending payments or unresolved ownership. |
| Subscription / payment management / Retry | Opens relevant billing controls for a blocking subscription/payment, then rechecks eligibility. |
| Manage owned group chats | Resolves representative ownership before continuing. |
| Provider verification | Confirms the original Google or Apple account. |
| Continue / Cancel verification | Advances from the warning to verification or cancels pending verification where offered. |
| Confirmation text | Enter DELETE exactly as displayed. |
| Confirm / Request deletion | Requests deletion after verification and confirmation. |
| Check result / Check request status | Resolves an uncertain result without blindly resubmitting. |
| Receipt / Sign out | Shows the accepted request's recovery deadline and finishes sign-out. An uncertain-state Sign out allows reauthentication to check status. |

## Conditions and results

This signs out all devices and revokes saved payment methods and agent tokens. Recovery is available for 30 days by signing in with the original account. Verification alone does not delete the account. Completed room ownership transfers and room closures are not undone by cancelling account deletion.
