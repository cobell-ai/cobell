# Create and maintain a Flow: screen reference

Create an orchestration, change its identity or manage the Flow catalog.

## Open this screen

**Desktop:** Flow in the main navigation.

**Mobile:** Fourth bottom tab Flow → Flow list.

## Controls

| Control or area | Behavior |
|---|---|
| Sort | Last modified, name or reverse name order. |
| Refresh / Retry | Refreshes the catalog or retries a failed load. |
| Add / Create Flow | Opens creation. Name and description are required. Desktop collects them in successive steps; mobile uses a form. |
| Next / Back / Cancel | Moves through desktop creation steps or abandons creation. |
| Flow row | Opens the editor; in selection mode it selects the Flow instead. |
| Edit / Select | Enters selection mode. Select entries, delete the selection with confirmation, or leave selection mode. |
| Name / description | Desktop editor header opens separate editors. Mobile provides metadata editing from the Flow screen. Save or cancel the metadata edit. |
| Avatar | Opens the Flow image actions where offered. |
| Duplicate | Creates a separate Flow from the chosen Flow. |
| Execution history | Opens recorded runs for this Flow. |
| Run Flow | Mobile row menu opens the run sheet. Starting requires a further action there. |
| Delete | Confirms removal of the Flow and its associated chat. |

## Conditions and results

Creation does not run the Flow. A new graph still needs task nodes and execution assignments. Catalog selection and canvas node selection are separate controls. Deletion errors must be resolved before treating an entry as removed.

Names accept up to 40 characters and must satisfy the displayed name validation. [Flow image controls](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/ui/flows/image.md) cover reference selection, style, generation, application and removal.
