# View several chats at once: screen reference

Arrange existing chat rooms in a desktop grid.

## Open this screen

**Desktop:** Click the grid icon near the upper-right, with tooltip Multi Chat.

**Mobile:** The mobile app opens individual rooms; the desktop Multi Chat grid is not provided.

## Controls

| Control or area | Location and behavior |
|---|---|
| Layout icons | Lower part of the left navigation panel; choose the grid arrangement. |
| Select Chat Room | In an empty slot; opens the room selector. |
| Recent Chat Rooms | Shortcuts within an empty slot. |
| Search / category tabs | Filter selectable rooms. |
| Selectable chat rooms only | Hides disabled entries in the selector. |
| Close | Removes the assigned room from that slot. |

## Conditions and results

Each slot uses ordinary room controls. Disabled rooms cannot be selected. A slot load error has its own close action.
