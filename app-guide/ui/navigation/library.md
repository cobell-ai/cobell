# Use Library prompts: screen reference

Review a template and send its prompt to Cobelly, with optional edits.

## Open this screen

**Desktop:** Start → empty landing → Library.

**Mobile:** Home → Library. A received Library link opens the identified template.

## Controls

| Control or area | Behavior |
|---|---|
| Category tabs | Switches prompt groups. Leaving a dirty edit requires resolving it first. |
| Prompt list | Opens a template detail. |
| Load more / Retry | Loads further entries or retries a failed initial/detail/page read. |
| English title/body preview | Shows the canonical prompt that direct publication sends, even when the listing title is localized. Available on both platforms. |
| Publish without edits / Publish this prompt | Sends the canonical English title/body to Cobelly. |
| Edit and publish / Edit before publishing | Opens Title and Prompt fields initialized from canonical content. |
| Title / Prompt | Accepts up to 256 / 65,536 characters. Both must be nonempty to publish. |
| Publish / Publish to Cobell | Sends the reviewed edit. |
| Cancel editing / Back / Esc | Leaves the edit/detail/list as applicable. Desktop also supports Esc. Dirty drafts require Keep editing or Discard. |
| Check delivery | Desktop resolves an uncertain publication using the original submitted message. Editing is locked while delivery is uncertain. |
| Copy link | Shares this template's public link; it does not publish the prompt. |

## Conditions and results

Personal sign-in and a ready Cobelly are required. Publication creates a Cobelly request; it does not save a private Library template or overwrite the published item. Mobile opens the resulting thread after the message is accepted and can separately report an AI-command failure.

Use Check delivery for the desktop uncertain state before creating a new request. A failed read/publication is not success. Opening a public link only opens the template for review.
