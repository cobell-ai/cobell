# Browse knowledge files across devices: screen reference

Choose a source device and inspect its workspace without assuming its files were copied to every device.

## Open this screen

**Desktop:** Management → Pure → select your DingDong → KnowledgeBox → the device/scope selector and tree.

**Mobile:** Shortcuts → DingDong → select your Pure → Knowledge → Files; use the device/source selector to choose the workspace.

## Controls

| Control or area | Behavior |
|---|---|
| Device/source selector | Desktop offers this device and online desktop devices; its same menu can switch to the Link collection. Mobile lists this phone and other registered devices with access state; only available sources can be selected. |
| Source Refresh | Mobile reloads the device inventory/settings. Loading, disabled access, offline or unavailable state is distinct from a missing file. |
| Folder row / expand | Desktop expands/collapses the tree. Mobile enters the selected folder. |
| Parent folder | Mobile returns to the enclosing folder; shown below the workspace root. |
| Sort | Desktop: name A–Z/Z–A, newest/oldest, or type. Mobile: name, modified time or size, each ascending/descending. |
| Refresh / pull to refresh | Reloads file information; mobile offers both the button and pull gesture. A failed read reports the cause and can disable row actions. |
| File row | Opens the selected content view; supported preview/editing depends on the entry and source. Mobile refreshes the original list after returning if its source is still current. |
| Info/details | Mobile info button opens entry metadata and rename/metadata/delete actions. A folder's details can also open Add for that directory. |
| Add | Opens creation or file/folder import for the selected destination. Desktop uses a selected directory, the selected file's parent, or workspace root if nothing is selected. Mobile uses the displayed current directory. |
| Workspace settings / Knowledge folder | Opens the current device's binding setup/status. Mobile root actions can be expanded/collapsed separately. |
| Deselect / Show in file explorer | Desktop context menu clears selection or reveals an eligible local entry. A remote row does not provide local reveal. |

## Conditions and recovery

A listed entry can have metadata without accessible content. The owning device, KnowledgeBox permission, current workspace and supported connection/preview still matter. Selecting a device does not copy its workspace here.

If the source is offline or access is disabled, restore the device/permission and refresh. For unavailable/pending workspace or recovery messages, open the folder settings or recovery view before repeating mutations. A row disabled after a failed read is not evidence that the file was deleted.
