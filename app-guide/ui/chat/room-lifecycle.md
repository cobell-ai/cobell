# Hide, leave, close or clear a chat: screen reference

Choose the room operation whose effect matches your goal.

## Open this screen

**Desktop:** Chat panel → right-click the room row → Chat Room Settings → the bottom room actions.

**Mobile:** Second bottom tab Chat → open the room → gear → Danger Zone.

For an eligible room, Chat also offers Leave chat by swiping the row left in English/Korean layouts, long-pressing it or tapping its more button.

## Controls

| Control or area | Location and behavior |
|---|---|
| Delete Data / Delete Chat Data | Clears message data while leaving the room active. |
| Hide Chat Room | Removes the room from the normal list without deleting it. |
| Leave Chat Room / Leave chat | Leaves membership and clears local room data. |
| Close Chat Room | Ends the room for all participants, retaining downloaded local messages. |
| Remove Chat Room | Closed-room local removal; other devices and server are unaffected. |
| Check status / Retry | Resolves uncertain mobile results or retries pending local cleanup. |

## Conditions and results

Clearing data does not stop new messages. Hiding is reversible through Hidden Chats. Leaving can require an invitation to rejoin. Closing is for everyone; saved history becomes read only. Do not treat these controls as interchangeable.

The mobile list's Leave chat shows the room name and asks for Cancel or Leave chat. The action is absent for Cobelly, blocked or unsupported rooms and group representatives; an active group participant is required. If the result is uncertain, the notice's Check status opens room settings to inspect it. If leaving succeeded but local cleanup remains, Retry retries that cleanup. A generic failure notice does not confirm that the room was left. Reopen the current controls if the account, room or page changed while confirming.
