# Received links: screen reference

Open a Cobell friend, chat-invitation or Library link from a browser or another app. The web page offers Open in Cobell and Copy link; complete sign-in if required. Opening a link does not itself send a friend request or join a chat.

| Control or area | Behavior |
|---|---|
| Preview | Shows available profile information and any automatic friendship/chat/AI effects. An owner can see This is your link. |
| Send friend request | Submits the reviewed friend request. |
| Join | Attempts entry or submits an approval request according to the chat's policy. |
| Updated policy notice | Requires reviewing the refreshed information before trying again. |
| Pending approval / request sent / joined | Reports the outcome. Pending approval is not active membership. |
| Desktop Open chat | Opens a resulting chat when available. |
| Mobile Continue | Continues to the destination after processing and synchronization. Successful flows may navigate there directly. |
| Desktop Refresh account / mobile Refresh data | Retries data synchronization after an action succeeded but local data refresh failed. |
| Check status | Checks the original request when its result is unknown. The submit action stays disabled. |
| Retry | Reloads an unavailable preview; it is separate from resubmitting a request. |

Library links open the specified Library item. Publishing its prompt is a separate action. Expired, revoked, exhausted or otherwise inaccessible links cannot be used.
