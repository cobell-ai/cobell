# Read human participant profiles: screen reference

Inspect a person’s relationship, available chats and room-specific actions.

## Open this screen

**Desktop:** Click the person’s avatar in the friend list, room header or message. Clicking your own avatar inside a room opens your own profile dialog.

**Mobile:** Tap the person’s avatar in a friend/participant list or message.

## Controls

| Control or area | Location and behavior |
|---|---|
| Avatar / name / joined information | Identifies the selected human. |
| Relationship label | Friend or no direct relationship in public friend chats. |
| Chat Rooms | Lists accessible direct/group conversations with this person. |
| Create New Room / New Group Chat | Starts an eligible chat from the profile. |
| Send Friend Request / Request sent | Handles the friendship request. |
| Unfriend / Block / Unblock | Opens relationship-impact confirmation. |
| Kick / manager / representative actions | Conditional room administration. |
| My DingDongs in this chat / Invite DingDong | Own-profile dialog controls for your bots. |
| Refresh / Back / Close | Reloads or returns from the profile. |

## Conditions and results

The profile’s actions depend on the current account, relationship, room and role. A user without an explicit friendship cannot start a new friend direct room. Blocking, unfriending and kicking are different actions. Your global Profile page differs from the compact in-room own-profile dialog.
