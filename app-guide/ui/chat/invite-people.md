# Invite people and approve entry votes: screen reference

Add regular or guest participants and handle invitation approvals.

## Open this screen

**Desktop:** Chat panel → right-click the room row → Chat Room Settings → Invite People.

**Mobile:** Second bottom tab Chat → open the room → gear → Invite.

## Controls

| Control or area | Location and behavior |
|---|---|
| Roster / People | Selects candidate people. |
| Regular / Guest | Participation mode for each selected person. |
| Invite / Invite (count) | Submits the selected invitations. |
| Vote / Votes | Lists pending entry approvals. |
| Approve / Reject | Records the user’s decision. |
| Voter list | Shows required approvals and their current state. |
| Mobile post-creation invitation banner → Retry | Retries the stored invitation selection for the existing room. Disabled with progress while running; failure keeps the banner. This does not create another room or approve votes. |

## Conditions and results

Guests see messages sent after they joined and cannot invite their own DingDongs. A guest with Bell access can still ask a participating DingDong about earlier AI-visible context. Managers-only invitation settings and blocked-user/DingDong-owner conflicts can prevent completion.
