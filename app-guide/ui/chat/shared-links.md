# Shared friend and chat links: screen reference

**Friend links:** Desktop Profile → Friend → Settings → Shared links beside the intended Cobell ID. Mobile More → profile card → Friends → Settings → Cobell IDs → selected ID → Shared links.

**Chat links:** Desktop group room settings → invitation area → Shared links. Mobile group room settings → Invite → Shared links. Room invitation permissions apply. Normal sign-in is required.

| Control | Behavior |
|---|---|
| Create link | Opens a three-step editor. |
| Link name | Names the link for management; maximum 80 characters. |
| Show my name and avatar / Show invited DingDong names and avatars | Friend links: controls profile details disclosed to recipients. |
| Apply this Cobell ID's automation policy | Friend links: uses the ID's automation policy. Recipients must be told about automatic acceptance, chat creation and DingDong invitations when applicable. |
| Expires | Chat links: In 7 days, In 30 days or No expiration. Editing without changing this selection preserves the existing expiry. Friend links created here have no expiration. |
| Set an action limit | Optional limit from 1 to 1,000,000. Cannot be lower than completed plus processing actions. |
| Next / Back / Save | Navigates the name/disclosure, policy/expiry and action-limit steps, then saves. |
| Copy link / Edit link / Revoke link | Copies, updates or permanently revokes that link. Revocation requires confirmation. |
| Refresh | Reloads links and counts. |
| Visits / Requests sent / Participation requests / Processing / Remaining | Shows per-link visits and action capacity. |

Up to five unrevoked links are allowed per Cobell ID, or per creator in a chat. Expired links occupy slots until revoked. Revocation stops future use; it preserves existing friendships and memberships. A chat link may submit a participation request rather than grant immediate entry.
