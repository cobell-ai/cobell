# Send and handle friend requests: screen reference

Add a person using their Cobell ID or discoverable email and review incoming requests.

## Open this screen

**Desktop:** Click your avatar/name near the upper-right → Profile → Friend, or use Fr → Friends → Add Friend in the chat panel. The panel action starts at Inbox; use Send Request to send a new request.

**Mobile:** Home → Friends → Add friend, or Profile → Friends and its management action.

## Controls

| Control or area | Location and behavior |
|---|---|
| Desktop Inbox / Send Request / Settings | Friend management tabs. |
| Mobile Inbox / Send / Settings | Corresponding tabs. |
| Cobell ID or email | Input for the recipient’s discoverable identifier. |
| Send Request / Send friend request | Sends one request. |
| Inbox Accept / Reject | Handles a received request. |
| Refresh | Reloads pending requests. |
| Human profile Send Friend Request | Requests friendship from an available profile. |

## Conditions and results

The recipient must enable discovery for the chosen identifier. A sent request is not yet a friendship. A failure retains the input for correction or retry.
