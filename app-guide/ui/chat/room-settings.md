# Open room settings and participant profiles: screen reference

Find room controls and distinguish them from each DingDong’s settings.

## Open this screen

**Desktop:** In the chat panel's All directory, right-click the room row → Chat room settings. The row's gear starts at DingDong settings; use its header switch for Chat room settings.

**Mobile:** Open the room and tap the upper-right gear icon.

## Controls

| Control or area | Location and behavior |
|---|---|
| Back / Esc (desktop All) | Returns from settings to the directory. |
| Chat Room Settings / DingDong Settings | Desktop header chat-bubble and robot buttons switch the two configuration views. |
| Participants / People and DingDongs | Opens the roster and profiles. |
| Room name / Notice / Invite | Opens each room operation. |
| Room Management / Roles | Representative and manager controls when eligible. |
| Danger Zone | Room data, visibility, closure and leaving controls. |
| Room-row avatar (desktop) | Human-only direct rooms with exactly one other person open that profile; single-DingDong rooms open a resolvable bot profile. Other cases open participants. |
| Room header avatar / participant avatar | Opens the relevant participant view or profile. |

## Conditions and results

Ownership, room type and participation role determine which controls exist. Closed rooms show a read-only local-history view with Remove Chat Room; normal server mutations are not available there.
