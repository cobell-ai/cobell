# Translate or rewrite displayed messages: screen reference

Configure a display transformation and switch between the original and transformed text.

## Open this screen

**Desktop:** Chat panel → open the room → composer → Translate / Rewrite, then the language or rewrite setup controls.

**Mobile:** Use Translate/Rewrite beside the composer and its configuration panel.

## Controls

| Control or area | Location and behavior |
|---|---|
| Translate / Rewrite | Chooses the transformation mode. |
| Language / Target language | Selects or directly enters a translation language. |
| Rewrite requirements | Defines exactly how to change the text. |
| Translation Memory / Memory | Adds tone, terminology or other guidance. |
| Recent settings | Reuses previous configuration. |
| Show translations/rewrites for my messages | Includes your own messages in the display transformation. |
| Show original / Show translation / Show rewrite | Switches a bubble’s display. |
| Retry translation / rewrite | Retries a failed transformation where offered. |

## Conditions and results

Once enabled, the mode automatically processes eligible text messages, including new messages. It changes your view; original messages and other participants' views remain unchanged. Files, system events and actively streaming AI responses are not transformed. The own-message toggle controls whether your sent messages are included.

Rewrite follows the requirements you enter; it does not assume a language. Missing language/requirements must be filled before enabling the corresponding mode.
