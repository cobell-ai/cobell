# Transfer a file with a P2P offer: screen reference

Send a file as a transfer offer and track the recipient’s acceptance.

## Open this screen

**Desktop:** Chat panel → open the room → composer → Send P2P file.

**Mobile:** Open the chat → composer → More → Send P2P file, when available.

## Controls

| Control or area | Location and behavior |
|---|---|
| Send P2P file | Opens the file picker on desktop or mobile. |
| Accept / Reject | Receiver chooses whether to transfer to the eligible device. |
| Peer status rows | Waiting, accepted, transferring, completed, rejected or failed for each peer. |
| Countdown / Expired | Shows the offer’s remaining acceptance window. |
| Another device notice | Identifies an offer not intended for this device. |

## Conditions and results

Acceptance alone is not transfer completion. Expired or device-ineligible offers cannot be treated as ordinary attachments. Receiver failures offer retry where available.
