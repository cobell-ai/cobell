# Write a room notice: screen reference

Publish a room notice separately from ordinary chat messages.

## Open this screen

**Desktop:** Chat panel → right-click the room row → Chat Room Settings → Notice → Write Notice or Edit; the pinned notice bar also has Edit notice.

**Mobile:** Second bottom tab Chat → open the room → gear → Notice.

## Controls

| Control or area | Location and behavior |
|---|---|
| Title / Content | Edits notice text. |
| Save | Publishes the notice. |
| Delete Notice | Removes the notice after confirmation. |
| Expand / Collapse / Minimize / More | Changes the desktop notice-bar presentation or opens its detail. |

## Conditions and results

Room participants and their DingDongs can read the published notice. Editing and deletion depend on room permissions.
