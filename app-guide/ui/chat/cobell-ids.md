# Manage Cobell IDs and friend discovery: screen reference

Create an identifier other people can use and control who may request friendship.

## Open this screen

**Desktop:** Click your avatar/name near the upper-right → Profile → Friend → Settings.

**Mobile:** Friends management → Settings → Cobell IDs.

## Controls

| Control or area | Location and behavior |
|---|---|
| Create Cobell ID / Create | Adds a new 3–30 character identifier. |
| Allow requests by email / phone | Controls account-level discoverability. |
| Allow friend requests via Cobell ID / Active | Enables the selected identifier. |
| Auto accept / Automatically accept requests | Accepts matching ID requests automatically. |
| Auto-create chat / Automatically create a chat | Creates a room for accepted requests. |
| Increase ID limit / Plan limits | Explains plan capacity and annual creation allowance. |
| Delete Cobell ID | Confirmation action; annual policy applies. |

## Conditions and results

Cobell IDs use letters, numbers, underscores, dots or hyphens and have current-held and yearly-creation limits. Deleting an ID does not replenish the creation allowance. Phone discovery can reflect an already registered phone, but the current mobile version says phone registration is unavailable.
