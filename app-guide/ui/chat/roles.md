# Manage representatives, managers and kicked users: screen reference

Manage participation roles in a group you are authorized to administer.

## Open this screen

**Desktop:** Chat Room Settings → Room Management; participant profiles also expose permitted role actions.

**Mobile:** Room settings → Roles → Representative, Managers or Kicked Users.

## Controls

| Control or area | Location and behavior |
|---|---|
| Representative / Delegate Representative | Transfers the representative role. |
| Manager / Managers | Appoints or dismisses permitted managers. |
| Only admins/managers can invite | Restricts human invitations. |
| Kick / Remove Participant | Removes a human; removing an owner can remove their DingDongs. |
| Kicked List / Kicked Users | Reviews removed participants. |
| Unkick / Restore | Allows an eligible kicked person to rejoin when invited. |

## Conditions and results

Role changes require the corresponding authority. A representative may need to appoint another person before leaving. Removing a human owner also affects their invited DingDongs; previous messages are not automatically deleted.
