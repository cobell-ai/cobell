# Understand a possible message gap: screen reference

Read the uncertainty marker when this device cannot recover a range of room history.

## Open this screen

**Desktop:** In the conversation, click the dashed/scissors separator labelled Messages may have been unavailable in this section.

**Mobile:** Tap the equivalent dashed/scissors separator in the message list.

## Controls

| Control or area | Location and behavior |
|---|---|
| Gap separator | Marks the range this device could not recover. |
| Possible message gap | Opens the explanation dialog. |
| Close | Returns to the conversation. |
| Load earlier history | Ordinary history paging; does not guarantee the unavailable range can be reconstructed. |

## Conditions and results

The marker does not prove a visible chat bubble is missing. Unavailable rows may have been non-display events or content expired/deleted before recovery. The app retains the separator to make that uncertainty visible.
