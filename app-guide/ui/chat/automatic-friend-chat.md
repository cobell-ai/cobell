# Configure automatically created friend chats: screen reference

Choose the room-name template and DingDongs used when a Cobell ID creates a chat.

## Open this screen

**Desktop:** Click your avatar/name near the upper-right → Profile → Friend → Settings → the Cobell ID’s automatic chat controls.

**Mobile:** Friends management → Settings → select the ID → Automatic chat DingDongs and Gears.

## Controls

| Control or area | Location and behavior |
|---|---|
| Auto-created chat room name / Chat room name template | Editable naming template. |
| Insert variable | Inserts requester name, creation time or short code. |
| Date format / Timezone | Formats a creation-time variable. |
| Add DingDong | Chooses an owned DingDong and Gear for the automatic room. |
| Active / Mode / Bell permission / Intelligence / Auto Reply | Sets behavior for that automatic invitation. |
| Edit / Remove / Save | Changes or removes a configured automatic pair. |

## Conditions and results

Final room names are limited to 40 characters and variable expansion can be shortened. Put must-keep text first. A DingDong’s new shared chat invite policy can prevent automatic participation; existing chats are not retroactively changed.
