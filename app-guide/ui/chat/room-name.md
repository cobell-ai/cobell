# Rename a chat room: screen reference

Change a room’s display name when your role permits it.

## Open this screen

**Desktop:** Chat panel → right-click the room row → Chat Room Settings → Chat Room Name or DingDong Name edit control.

**Mobile:** Second bottom tab Chat → open the room → gear → Chat Room Name.

## Controls

| Control or area | Location and behavior |
|---|---|
| Desktop name pencil | Opens Change Chat Room Name or the bot-name dialog. |
| New Name / mobile name field | Enter the proposed name. |
| Change / Save | Saves a valid edited name. |
| Cancel / Back | Leaves the editor; mobile can ask to discard a dirty draft. |

## Conditions and results

Auto-created friend chat names can be editable only by the person whose ID created them. Group roles can restrict name changes. Read-only or invalid input does not enable saving.
