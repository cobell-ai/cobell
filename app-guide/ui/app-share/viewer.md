# App viewers: screen reference

**Desktop:** Apps → select an app, or chat header → Apps → app. **Mobile:** Shortcuts → Apps → select an app, or chat header → Apps → app.

| Control | Behavior |
|---|---|
| Chat Apps overlay → Refresh / Close | Reloads the room's shared-app list or returns to chat. Closing this list does not close a viewer. |
| Room choice | Selects the chat share used to open the app. |
| Run | Opens an owned app whose static folder is linked to this device. Desktop shows this in the selected app's menu or Operate. On mobile, open the app details. |
| Reset app data | Clears this app's saved data on this device and keeps its source files. |
| Desktop Minimize | Retains the viewer as a floating chip. Click the chip to restore; drag it to move. |
| Desktop Show icon only / Color | Collapses the floating chip; hover the icon for its color menu. |
| Desktop Open in Chrome | Opens Chrome with separate app data from the built-in viewer. |
| Desktop Close / mobile Close connection | Ends the viewer connection. |
| Mobile Back | Leaves the viewer page while retaining the connection. Reopen it under Apps → Open connections. |
| Status overlay | Displays pause, hold, offline, limit or terminal-connection reasons. |

Normal sign-in is required for shared and local viewing. The iOS viewer requires iOS 17 or later. The embedded macOS viewer requires macOS 14 or later. Open in Chrome is available on desktop.
