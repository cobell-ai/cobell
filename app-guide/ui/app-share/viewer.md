# Shared app viewers: screen reference

**Desktop:** Apps → available app, or a chat header's Apps grid button → app. **Mobile:** More → Apps → room share → Open app, or chat header → Apps → app.

| Control | Behavior |
|---|---|
| Chat Apps overlay → Refresh / Close | Reloads the room's shared-app list or returns to chat. Closing this list does not close a viewer. |
| Room choice | Selects the share used to authorize the connection. |
| Desktop Minimize | Retains the viewer as a floating chip. Click the chip to restore; drag it to move. |
| Desktop Show icon only / Color | Collapses the floating chip; hover the icon for its color menu. |
| Desktop Open in Chrome | Switches to a fresh Chrome browser. App login, storage and unfinished forms are not transferred. |
| Desktop Close / mobile Close connection | Ends the viewer connection. |
| Mobile Back | Leaves the viewer page while retaining the connection. Reopen it under Apps → Open connections. |
| Status overlay | Displays pause, hold, offline, limit or terminal-connection reasons. |

Normal sign-in is required, including for an app owned by the same account or running on the same desktop. Agent sign-in has no local testing exception. The embedded macOS viewer requires macOS 14 or later; use Chrome on older macOS.
