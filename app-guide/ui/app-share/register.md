# Apps and registration: screen reference

**Desktop:** Top navigation → Apps (grid icon). **Mobile:** Shortcuts → Apps.

| Control | Behavior |
|---|---|
| All / All apps, My apps, Other people’s apps | Filter the catalog by ownership. |
| Device filter | On desktop, select a device in the catalog sidebar. On mobile, **Only apps on this device** shows owned apps linked to the current device. |
| Refresh | Reloads available apps and sharing state. |
| Register app | Enter an app name (up to 80 characters). Desktop and mobile offer Choose KnowledgeBox folder for static files. Desktop also accepts a local server address. |
| Create avatar / Skip for now | Registration has already completed. The owner can generate and review an avatar now or return through Operate → Settings. |
| Desktop Integration configuration file | Shows the generated file path after registration; the copy icon copies the path. The local app must read the configuration and implement the App Share status endpoint. |
| App card / Open app | Select an app to see its details, then open an available share. If prompted, choose a chat. |
| Run | Opens an owned app from a static folder linked to the current device. |
| Operate | Opens an owned app's operation screen. |
| Mobile Open connections | Reopens retained viewer connections. |

Registering with a folder selects this device as host. Mobile name-only registration leaves host selection for Operate. Enable the intended chat share there. For an app you registered manually, select it in Gear to let a DingDong manage it.

Normal sign-in opens Apps and the viewer. On a mobile agent session, Hosting on this device shows the local hosting status for apps with sharing enabled.
