# App operation and access: screen reference

**Desktop:** Apps → owned app → Operate. **Mobile:** More → Apps → owned app → Operate. Both require normal sign-in as the app owner.

| Control or area | Behavior |
|---|---|
| Host and runtime summary | Shows the selected host, verification, availability, runtime mode and pause state. |
| Pause all sharing / Resume sharing; mobile Paused switch | Pauses or resumes this app across its shared chats. |
| Rooms → Add; mobile Share with a chat | Opens the eligible-chat picker. |
| Room row | Expands participant and traffic details. |
| Room sharing switch | Enables or disables this app in that chat. |
| Block access / Unblock; mobile Allow access | Changes one participant's access through that chat's share. |
| Usage | Shows plan, monthly traffic, active apps, this app's connected users and concurrent users across all apps. |
| Participant details | Shows connection state, last connection and received/sent traffic. |
| Settings / Change host | Opens app settings or selects an existing desktop binding. Desktop also has This device's binding. |
| Refresh | Updates operation and connection data. |

An enabled share may still be unavailable because the host/app is offline, verification is incomplete, sharing is paused or a plan limit is reached. A chat share requires current participation; knowing an app address is insufficient.
