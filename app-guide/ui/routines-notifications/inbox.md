# Read and manage notifications: screen reference

Read DingDong notifications and open their destinations or triggering records.

## Open this screen

**Desktop:** Notification outline icon near the upper-right.

**Mobile:** Home → notifications icon.

## Controls

| Control or area | Behavior |
|---|---|
| Notification card | Shows title, content, source and read state. Clicking/tapping marks it read and opens its supported destination. |
| Mark all read | Marks DingDong notifications read. |
| Execution history | Desktop card icon opens this notification's triggering records. |
| Trigger history | Mobile card overflow menu opens the same type of event records. |
| Delete notification | Desktop card icon or mobile overflow action; asks for confirmation. |
| Retry / pagination | Retries failed reads and loads additional entries. Mobile also supports refresh. |
| Announcements | Mobile shows active service announcements alongside DingDong notifications; opening an announcement can show details or its action link. |
| Close / Back | Leaves the inbox. |

## Conditions and results

Opening a notification can navigate to its linked chat/thread or open a supported external URL. Review any failed-open message. Deleting a notification does not delete its rule or stop work. Reading it does not establish that triggered work completed.
