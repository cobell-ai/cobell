# Browse a DingDong's chats: screen reference

## Open this screen

**Desktop:** Management → Pure → select your DingDong → Chat. The list header is Chats.

**Mobile:** Shortcuts → DingDong → select your Pure → Chats.

## Desktop controls

| Control or area | Behavior |
|---|---|
| Header Chat / K-Box / Back | Chat selects the chat panel; K-Box opens KnowledgeBox. Header Back returns to Management. Save file edits before using these controls: they do not run the resource-tab Save/Discard/Cancel check. |
| All / DD / Gen | Filters the list. The selected button uses its full label: All, DingDong or General. General includes friend direct and group chats. |
| Room row outside Edit | Selects a room for the adjacent content area. With no explicit selection, the personal DingDong chat is the default. A shared-room selection can leave the content asking to select a chat room; open that room from the main chat panel instead. |
| Personal chat pin | Marks the fixed personal row. This management list has no pin/unpin or reorder action. |
| Room avatar outside Edit | Opens the corresponding profile/participant view. It is separate from selecting the row. |
| Row settings gear outside Edit | Opens DingDong settings for that room in the left panel. Back or Esc returns to the list. |
| Row right-click menu | Its visible DingDong settings and Chat room settings items currently have no action in this management list. Use the row's settings gear for DingDong settings. |
| Edit / row checkbox | In Edit, click an eligible row or its checkbox to toggle removal selection. The fixed personal chat cannot be selected; avatars, row gears and pin controls are hidden or inactive in this mode. See the management-removal section of Remove a DingDong from one chat for Delete, cancellation and uncertain removal checks. |
| Cancel / Esc in Edit | Clears removal selection. Cancel is disabled while removal is busy. Esc does not undo requests already sent. |
| DingDong not found → Back | Returns to Management. This state has no Retry control. |
| Join / empty General → Join general chat room | Opens the existing-room join dialog. Merely opening it does not join a room. Available for supported non-system DingDongs; the header Join is outside Edit. |
| List refresh-error Retry | Refreshes room information without repeating a join or removal. If no retry is offered, reopen the list. |
| Content refresh-error Retry | Refreshes the selected room without resending messages. If no retry is offered, reopen the room. |

## Mobile controls

| Control or area | Behavior |
|---|---|
| Chat row / trailing chevron | Opens the room's chat screen directly; no adjacent content pane. |
| Row swipe action / long-press → Open | Opens the same room. Tapping a row with its swipe rail revealed closes the rail first; tap again to open normally. Dismissing the action menu does not open it. |
| Join chats | Opens target selection for a normal account's owned supported DingDong. Preview and agent login do not offer this action. |
| Invitation policy | Controls new shared invitations for the owned bot; see its separate guide. |
| Empty Chats | Shows no chats. Join chats can still be offered when eligible. This tab has no desktop-style All/DD/Gen filter or row-removal selection. |

## Conditions and recovery

A listed room is not proof of a successful new invitation or removal. After an uncertain membership change, inspect the current participants and follow its operation-specific recovery guide. A room may be unavailable or read-only when access changes.
