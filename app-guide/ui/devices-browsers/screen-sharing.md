# Mobile screen sharing: screen reference

**Mobile:** More → Screen sharing, or use the Screen sharing card in the Gear's Screen Use configuration. Agent sign-in also has a screen-sharing entry. **Desktop:** Configure Screen Use in Gear.

| Control or area | Behavior |
|---|---|
| Start sharing | Starts the system screen-capture approval flow. |
| Android system prompt | Grants or denies capture using the OS controls. |
| iOS broadcast button | Appears while waiting. Tap it, then choose Start Broadcast in the system dialog. |
| Status | Shows off, waiting for approval, sharing, paused, reconnecting, denied or stopped/failed. |
| Stop sharing | Ends the session. System screen-sharing controls can also stop it. |
| Back | Leaves the settings page; use Stop sharing to end capture. |

Screen sharing lets a DingDong read the shared screen when requested. It does not provide mobile window enumeration, UI structure, mouse control or keyboard control. You perform taps and typing. Protected content may appear blank. Cobell Mobile Booster is not required. During a connection interruption, Cobell keeps the approved session and retries automatically. Stop sharing works offline.
