# Check and apply an app update: screen reference

Follow the current app’s update route when a version is available or required.

## Open this screen

**Desktop:** Use the optional/required update banner or version information on Profile.

**Mobile:** Fifth bottom tab More → App information, or a required-update screen/banner.

## Controls

| Control or area | Location and behavior |
|---|---|
| Current / Minimum / Latest version | Shows confirmed version information. |
| Check for updates | Refreshes mobile app-version information. |
| Update now | Opens or starts the configured update route. |
| Open download page | Desktop fallback if automatic update fails. |
| Restart / update-ready notice | Applies a downloaded desktop update. |
| Required-update countdown | Warns when the current version must stop. |
| Try again / Check again | Rechecks unavailable version/service information. |

## Conditions and results

Mobile automatic updates are managed in the app store. If version information has not been confirmed, do not claim the app is current. Required updates differ from optional banners and can end an unsupported session. Unpublished feature-enrollment controls are not covered by this guide.
