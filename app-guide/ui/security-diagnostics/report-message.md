# Report a message: screen reference

Send the specific message and reason to Cobell, with a separate optional user-block action.

## Open this screen

**Desktop:** Message More/right-click → Report.

**Mobile:** Message More → Report Message.

## Controls

| Control or area | Location and behavior |
|---|---|
| Reported message / Sender / Owner | Reviews the exact target. |
| Report reason | Selects the issue category. |
| Details | Optional explanation. |
| Also block this user / Block this bot’s owner | Requests the separate relationship action. |
| Report | Submits the report. |
| Result / Done / Try again | Shows accepted, failed or uncertain report status. |
| Rooms to resolve | Explains why optional blocking could not finish. |

## Conditions and results

Report and block are separate outcomes. An uncertain submission may already have been accepted; the mobile warning explicitly notes that submitting again can duplicate it. A failed report preserves the draft. Blocking an owner can affect all their DingDongs, not just the reported bot.
