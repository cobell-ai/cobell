# Hide sensitive information controls

**Desktop:** Security shield → Hide sensitive information. **Mobile:** More → Security → Hide sensitive information.

| Control | Behavior |
|---|---|
| Values to hide → Add a value | Enter the value on one line. Spaces, case, quotation marks and backslashes are significant. A multiline or overlong edit is rejected in full. |
| Apply to built-in Toolboxes | Select where this value should be hidden on this device. An empty selection turns off hiding for that value. |
| Save | Saves the rule on this device. Select an existing value to edit or delete it. |
| Successful hiding | Shows local replacement counts and the affected Toolbox. |
