# Review and send diagnostics: screen reference

Send the app’s offered technical diagnostic report and retain its report ID.

## Open this screen

**Desktop:** Click your avatar/name near the upper-right → Profile → Send diagnostics.

**Mobile:** Fifth bottom tab More → profile card → Send diagnostics.

## Controls

| Control or area | Location and behavior |
|---|---|
| Preview / Information to send | Reviews the prepared technical report. |
| Remove recent errors / Clear recorded errors | Clears locally recorded diagnostic events. |
| Send reviewed content / mobile send action | Sends the reviewed report. |
| Sending… | Shows a pending submission. |
| Report ID / success result | Identifies the accepted report. |
| Retry / Close | Retries failed submission or leaves the view. |

## Conditions and results

The mobile preview describes app details and error categories without messages, account details or file contents. Sending is a deliberate user action, not a consequence of merely opening the preview. A submission error does not produce a confirmed report ID.
