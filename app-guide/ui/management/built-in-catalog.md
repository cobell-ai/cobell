# Inspect built-in Toolboxes: screen reference

Choose a supplied capability and find the Gear settings that actually control it.

## Open this screen

**Desktop:** Management → Toolbox → B origin filter → select a Toolbox.

**Mobile:** Shortcuts → DingDong → Toolbox → Built-in filter → select a Toolbox.

## Controls

| Control or area | Location and behavior |
|---|---|
| Guide | Explains what the Toolbox does and how to set it up. Open Gear to configure it. |
| Gear usage | Lists loaded Gear with the Toolbox enabled. Names are display-only. Cobell Controller and Notification Sender omit this section. |
| Back | Desktop returns to Management. Mobile returns through its navigation stack, with Management as fallback. |

Built-in definitions have no private Rename, Duplicate, image or individual Delete menu. Desktop collection checkboxes do not make them removable; see [collection controls](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/ui/management/collections.md).

## Conditions and results

The catalog includes KnowledgeBox Use, Internet Use, Sandbox Browser Use, Screen Use, Mouse Use, Keyboard Use, Cobell Controller, Notification Sender and App Management. Gear usage reflects saved configuration. Check the chosen device and its permissions before asking a DingDong to use the Toolbox.
