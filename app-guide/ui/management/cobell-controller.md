# Control the Cobell app with Cobelly: screen reference

Cobell Controller is the built-in Toolbox for controlling the Cobell app and using its features. Cobelly uses the available tools to perform supported app actions on your behalf.

## Open this screen

**Desktop:** Start/System DingDong prompt, or a Memory/Gear creation dialog’s Create through conversation option.

**Mobile:** Home’s System DingDong prompt, or Create with System DingDong in configuration creation.

## Controls

| Control or area | Location and behavior |
|---|---|
| Assisted creation choice | Opens a conversation with a prefilled configuration request. |
| System DingDong prompt | Describes the app action you want and any constraints. |
| Question controls | Supplies information Cobelly needs to perform the action. |
| Cobell Controller detail | Shows the Toolbox overview and summaries of available capabilities. |
| Relevant app screen | Reviews the result of the action. |

## Conditions and results

Cobell Controller is automatically included for System DingDong Gear. Its catalog is a brief capability overview, not published hidden tool schemas. A saved object, a valid configuration and successful execution are separate completion stages.

The available tools determine which actions are currently supported. Actions that use a device still require that device and its applicable permissions.
