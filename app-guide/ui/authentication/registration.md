# Finish account registration: screen reference

Supply the additional information needed when signing in for the first time.

## Open this screen

**Desktop:** The provider sign-in opens Sign Up when the account is not registered.

**Mobile:** The provider flow opens Create account when registration is needed.

## Controls

| Control or area | Location and behavior |
|---|---|
| Nickname / Name | Enter the account display name. |
| Email | Shows the social account email. |
| Terms and privacy checkboxes / View | Both agreements are required. View or the document icon opens the corresponding reader; opening it does not check the agreement automatically. |
| Terms of Service / Privacy Policy after sign-in | Desktop: Profile → App info & support. Mobile: More. Use Retry if the reader cannot load. |
| Sign Up / Create account | Submits the registration. |
| Back / Back to login | Cancels the signup form and returns to sign-in when not submitting. Expired or already-registered attempts also require returning to sign-in. |

## Conditions and results

The name must use 1–40 supported letters, numbers or underscores and cannot be numbers only. An expired signup requires a fresh social sign-in. If the account is already registered, return to login.
