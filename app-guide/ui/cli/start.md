# Start Cobell in a terminal: screen reference

Use the supplied desktop CLI companion for a personal conversation.

## Open this screen

**Desktop:** Open a terminal where the installed cobell command is available.

**Mobile:** The CLI companion runs with desktop; mobile can approve its device login.

## Controls

| Control or area | Location and behavior |
|---|---|
| cobell | Opens a conversation/workspace selection in the current directory. |
| cobell login | Displays a code for approval from another signed-in app. |
| cobell status | Prints current session/device state. |
| cobell gui | Shows the desktop and leaves it running independently. |
| cobell cobelly | Opens the System DingDong. |
| cobell help / version | Shows command help or the installed version. |
| F1 / /help | Opens in-TUI command and keyboard help. |

## CLI

Run `cobell`, `cobell login`, `cobell status`, `cobell gui` or `cobell cobelly` from the installed companion. Inside it, `/gui` opens desktop and `/login` opens temporary sign-in.

## Conditions and results

Use the CLI distributed with the matching desktop app. Personal TUI conversations/management require normal login; agent mode is a separate device server. Do not build the app from source as a user installation step. No binaries are hosted by this documentation repository.
