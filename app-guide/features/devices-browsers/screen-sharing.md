# Let a DingDong read your mobile screen

1. On Android or iOS, open More → Screen sharing. The Screen sharing card in Screen Use's built-in catalog detail or Gear configuration also opens this page.
2. Choose Start sharing and complete system approval. On iOS, tap the broadcast button shown while waiting, then Start Broadcast in the system dialog.
3. Confirm that the status says Your screen is being shared. A waiting or denied status does not mean capture is active.
4. Ask the DingDong to inspect the shared screen. You perform any taps and typing yourself.
5. Choose Stop sharing here or stop through the OS controls when finished. Back only leaves the page.

Only the shared display can be captured; protected content may appear blank. Mobile does not supply screen structure, other app windows, Mouse Use or Keyboard Use. Booster pairing is not needed for screen sharing and does not enable mobile input control.

While the status says Reconnecting, leave sharing on to resume automatically when the connection returns. You can also stop sharing while offline. Once the session ends, starting a new one requires system approval. Saving a [Screen Use Gear configuration](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/management/screen-permissions.md) does not itself start an OS capture session.
