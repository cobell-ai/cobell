# Create and edit an isolated Browser

Save a named Browser on an owning device, then separately select it in a DingDong's Gear.

## Start here

**Desktop:** Management → Browser → Add; use the pencil to edit a row.

**Mobile:** Shortcuts → Browser → Create; open a Browser detail → Edit browser.

## Desktop steps

1. Open Management → Browser → Add.
2. Choose the owning device, enter a name and set Run in background.
3. Choose Next, configure the global policy, then Save. Previous returns to basic information; Cancel discards the draft.
4. Check the saved Browser in its device group. Use its pencil for later edits; the owning device remains fixed.
5. Add the Browser to Sandbox Browser Use in the intended Gear before asking a DingDong to use it.

## Mobile steps

1. Open Shortcuts → Browser → Create. Choose the local Android device or an available desktop device.
2. Set the display name, background mode, site scope and permissions, then Save.
3. Open the saved detail to edit it or inspect runtime state. Creating a Browser from Gear can return to that Gear's draft; save the Gear to persist its selection.
4. If another edit conflicts or saving cannot be resolved, use Reload latest settings, review the discard prompt and reapply your intended changes to the newly loaded settings.
5. Delete browser in the detail asks for confirmation. On desktop, check the row before using its trash icon.

## Completion, limits and recovery

Saved configuration and a running session are separate. Creating or renaming a Browser does not prove runtime readiness, approve it for Gear or move its profile to another device. iOS can configure eligible remote Browsers but cannot run one locally.

If saving reports failure, inspect/reload the list before creating another Browser: a save can succeed while the following refresh fails. On desktop, reopen Edit from the refreshed row after an unresolved edit; there is no in-dialog Reload latest settings button. Deletion removes the Browser configuration; it has no undo control.
