# Respond to a DingDong notification

## Configure the response

1. Create a DingDong-notification AI-response rule and select its room and responder.
2. Choose Current-room responder, or choose Other sources and add the sources to observe.
3. Enter optional title/content filters and the response prompt.
4. Choose the response destination. Original notification thread and child thread are available only for the current-room responder source.
5. Choose the normal-session execution condition, save and confirm the rule is enabled.

## Select other sources

Add Chat for a DingDong in selected/all other chat rooms, Flow for selected/all nodes with an optional assigned-DingDong filter, or All activity for a DingDong across chat and Flow work. See [notification source selection](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/routines-notifications/notification-sources.md).

## Completion and recovery

Blank filters match all applicable text. Inspect the originating notification's trigger history to see recorded targets and conditions, then inspect the destination chat for the result. If creation needs verification, refresh/retry verification before creating another rule.
