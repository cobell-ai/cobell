# Enable Cobell OS notifications

## Enable delivery

1. Open Profile → App preferences → Notifications on desktop, or More/Profile → OS notifications on mobile.
2. Turn on Receive notifications and wait for the preference to save.
3. On mobile, saving the enabled preference can automatically request an undecided permission. If Allow notifications remains, use it to request permission. For a blocked or unverified permission, use Open system settings when offered.
4. Return to Cobell and check the permission notice.
5. Confirm that the DingDong's Gear includes this device's Desktop/Mobile platform in its notification delivery target.

## Control what appears on this device

Under **Preview**, turn off **Message content** to hide the message text and **Profile and chat** to hide sender and chat details. With both off, alerts can still appear. Read the message in Cobell.

Turn off **Receive notifications** in Cobell to stop delivery to this device. The OS setting controls display. You can still read the Cobell inbox.

## Completion and recovery

Retry a failed setting load. If saving fails, inspect the current switch state and retry the change. Enabling display permission does not make Cobell observe other Android apps; use the Mobile notification-hook access settings for that separate purpose.

Wait for loading or saving to finish, then check the switch and permission status. Use Retry beside a loading or permission error when offered. If access is unavailable, follow the system-settings guidance and check permission again afterward.

Use the current normal account; agent and preview sessions do not show the card. After returning from system settings, check the permission status; returning alone does not mean access was granted.
