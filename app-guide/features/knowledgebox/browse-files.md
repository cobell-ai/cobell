# Browse knowledge files across devices

Choose a source device and inspect its workspace without assuming its files were copied to every device.

## Start here

**Desktop:** Management → Pure → select your DingDong → KnowledgeBox → the device/scope selector and tree.

**Mobile:** Shortcuts → DingDong → select your Pure → Knowledge → Files; use the device/source selector to choose the workspace.

## Desktop steps

1. Open the DingDong's KnowledgeBox and choose the owning device in the scope selector. Link collection is a separate view in that menu.
2. Expand folders and select a file to open its content. Use Sort or Refresh as needed.
3. Before using Add, check the selection: a folder is the destination, a selected file uses its parent, and no selection uses the root.
4. Use the row context menu to Deselect or reveal a local entry. Workspace settings opens this device's binding.

## Mobile steps

1. Open Knowledge → Files and choose an available source device. Refresh the source list if its state is uncertain.
2. Tap a folder to enter it; Parent folder goes up. The current path is shown above the list.
3. Use Sort for name/time/size order. Pull down or tap Refresh to reload.
4. Tap a file for its content, or its info button for metadata and actions. A directory's details can also open Add within it.
5. If setup is needed, expand the root actions and open Knowledge folder. After changing source, recheck the displayed path before importing or editing.

## Completion, limits and recovery

A listed entry can have metadata without accessible content. The owning device, KnowledgeBox permission, current workspace and supported connection/preview still matter. Selecting a device does not copy its workspace here.

If the source is offline or access is disabled, restore the device/permission and refresh. For unavailable/pending workspace or recovery messages, open the folder settings or recovery view before repeating mutations. A row disabled after a failed read is not evidence that the file was deleted.
