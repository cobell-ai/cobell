# Import a directory tree

Review a selected folder and import it as a folder under the chosen KnowledgeBox directory.

## Start here

**Desktop:** Management → Pure → select your DingDong → KnowledgeBox → choose destination → Add → Add folder.

**Mobile:** Shortcuts → DingDong → select your Pure → Knowledge → Files → enter destination → Add → Import folder.

## Desktop steps

1. Choose the workspace device and destination: selected folder, selected file's parent or root.
2. Use Add → Add folder and choose the source directory.
3. Review the source, planned file/folder counts, total size and any warning before importing.
4. Confirm the preview and inspect the resulting folder in the tree. Cancel leaves the preview without importing. The source folder name is retained in this dialog.

## Mobile steps

1. Open Files at the destination → Add → Import folder → Select folder.
2. Wait for selection/scanning; its Cancel can stop that preparation.
3. Set the destination folder Name. Review the counts and skipped entries, then expand Import preview to inspect the planned paths. The preview may not show every path.
4. Choose Import when ready and review any additional confirmation. If the source is too large, select a smaller folder or split the import.
5. On success, check the destination tree. To abandon an unstarted plan, use Cancel or confirm discard when leaving with Back.

## Completion, limits and recovery

Imports create a destination folder; an existing conflicting name is not silently replaced. Mobile can change the planned root name. On desktop, choose another destination or rename the source before selecting it again if the name conflicts.

Review the planned file and folder counts and any skipped entries. Links or unsupported/unreadable entries may be skipped. A folder cannot be copied into itself or a destination inside the source.

After a failure, inspect the destination and any recovery-required state before starting another import. Folder import reports one operation result, not a list of independently retryable files. Pending recovery needs review; repeatedly selecting the entire folder does not resolve an uncertain result.
