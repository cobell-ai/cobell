# Change editor preferences

Adjust the desktop local code editor's appearance and check the applied settings.

## Start here

**Desktop:** Code/text editor toolbar → Editor settings (gear icon).

**Mobile:** The separate code Editor settings screen is currently unavailable in normal use.

## Desktop steps

1. Open Editor settings from the editor toolbar.
2. Choose a font and size, from 10 to 22 in 0.5 steps. Choose separate light/dark syntax themes for the corresponding app appearance.
3. Set Line wrap, Code folding, Indent guide lines and Gutter divider. Changes apply as you use each control; there is no separate Save/Apply button.
4. Use Reset to defaults if desired. This immediately restores editor preferences, not file contents.
5. Close and confirm the editor appearance. If settings failed to load, use Retry before editing them.

## Mobile steps

1. Use the Knowledge file content screen for supported files; it does not open the separate Editor settings page.
2. Do not use the unavailable Editor's preview Auto save/Font size controls as instructions for real Knowledge files. See [Content editing](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/knowledgebox/content-editing.md) for that screen's save behavior.

## Completion, limits and recovery

Preferences are local to the signed-in normal account on this device. Closing the dialog does not discard changes. If storing them fails, values can revert; reopen and verify them.

Inlay hints, Document colors and Format on save currently store their switch values without applying them to editor behavior. Use explicit Format with a supported language server when needed. These controls do not promise automatic formatting.

Auto-save for local text is a separate toolbar toggle. This appearance dialog does not configure remote-file or rich-document persistence.
