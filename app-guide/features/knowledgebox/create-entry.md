# Create a file, document or folder

Create knowledge content directly on the selected workspace device.

## Start here

**Desktop:** Management → Pure → select your DingDong → KnowledgeBox → Add → New folder, Write directly or Write directly (web-only).

**Mobile:** Shortcuts → DingDong → select your Pure → Knowledge → Files → Add → New file or folder.

## Desktop steps

1. Select the owning device and destination folder. A selected file uses its parent; with no selection the target is the root.
2. Use Add → New folder, Write directly for a text file, or Write directly (web-only) for a rich document.
3. Enter the name and press Enter/checkmark. The rich-document option supplies `.ddjson`; a text file uses the extension you enter.
4. Use Esc/cross to cancel. An empty submission also cancels; losing focus does not save a nonempty name.
5. Open the created file to write and save its contents. Creating an entry and saving content are separate operations.

## Mobile steps

1. Open Knowledge → Files → the destination directory.
2. Use Add → New file or folder.
3. Choose Text file, Document or Folder and enter Name. Document appends `.ddjson` if absent; a text file does not add an extension for you.
4. Tap Add or keyboard Done. Successful files/documents open their content screen; a folder returns to the previous view.
5. Back with an entered name asks whether to keep editing or discard. Creation blocks leaving while busy.

## Completion, limits and recovery

Use one portable filename, without path separators, a trailing period or reserved names such as `CON`. App-reserved paths are also rejected. The complete name including extension must fit 255 UTF-8 bytes; non-ASCII characters can reach the limit before the character counter.

Desktop adds a numbered suffix for duplicates already known in its sibling list, such as `notes (1).txt`; inspect the created name. Mobile rejects an existing destination. A collision missing from a stale desktop list can also fail. Existing entries are not overwritten.

An unavailable source, changed workspace or recovery-required state needs attention before retrying. Check the file list after an uncertain creation result. Creating a missing app folder is a separate operation and does not recover deleted files.
