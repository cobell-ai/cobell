# Import files into KnowledgeBox

Copy selected files into a local or eligible remote workspace. This is separate from sending chat attachments.

## Start here

**Desktop:** Management → Pure → select your DingDong → KnowledgeBox → choose source/destination → Add → Add file.

**Mobile:** Shortcuts → DingDong → select your Pure → Knowledge → Files → enter the destination → Add → Import files.

## Desktop steps

1. Select the workspace device and intended destination in the KnowledgeBox tree.
2. Choose Add → Add file and pick the source files.
3. If more than 10 were selected, review the checkbox dialog, choose up to 10 and confirm. Cancel imports nothing from that selection.
4. Wait for the copy/upload. The last successful file can become selected. Read any failed-file message and inspect the tree before retrying those files.

## Mobile steps

1. Open Files on the intended source device and enter the destination folder.
2. Use Add → Import files. Check the displayed destination and choose no more than 10 files.
3. Review the names, then choose Import. Watch each item and the completed/total count.
4. After a recoverable failure, fix the cause and press Import again to attempt the remaining items; successful items are skipped.
5. If the screen reports pending recovery or a changed/unavailable workspace, leave the batch and inspect that state before retrying. Back with pending items asks whether to keep or discard the selection.

## Completion, limits and recovery

Files already imported remain if later items fail or you discard the selection. Existing destination names are rejected rather than overwritten; use another destination or rename the conflicting entry/source before retrying. Choosing files again replaces the mobile batch instead of appending to it.

Picker access, source-file existence, destination permission, storage and the connection affect success. A recovery-required, replaced workspace, lost access or offline failure can stop the remaining batch. Do not infer success for waiting/failed items from another item's completion. There is no separate per-item Retry control on the mobile import page.
