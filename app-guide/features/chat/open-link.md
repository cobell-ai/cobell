# Use a received Cobell link

1. Open the link. On its web page, choose Open in Cobell and finish normal sign-in if requested.
2. For a friend or invitation link, read the preview. Check the identity and any automatic acceptance, chat creation or DingDong invitations.
3. Choose Send friend request or Join. Opening the link alone performs neither action.
4. Read the result. A participation request awaiting approval does not mean you have joined.
5. Open the resulting chat or use mobile Continue when offered. The app may navigate directly after a confirmed result.

If the policy changed, review the new preview before submitting again. If the action succeeded but account/chat data did not refresh, use Refresh account on desktop or Refresh data on mobile. If the result is unknown, use Check status for the original request instead of sending another one.

A Library link opens its selected item. Read it and use its publishing controls only when you want to send the prompt to Cobelly; opening or copying the link does not publish it.
