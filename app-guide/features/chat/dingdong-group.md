# Create a DingDong group

Create a room for you and your DingDongs, without inviting other people.

## Desktop steps

1. In the chat panel, choose DD → Group → plus (New Chat).
2. Enter Room Name. Search by a bot's displayed name or type label.
3. Click eligible owned Pure DingDong rows to select them. Cobelly cannot be selected. Check the total count after changing search.
4. Click Create and wait. Success opens the room. If an explanation appears, dismiss it with Confirm and correct the draft before retrying.
5. Before submitting, Back or the containing panel's Esc leaves without saving or asking Save/Discard. Leaving after submission does not cancel the request; inspect the current room list before repeating an uncertain creation.

## Mobile steps

1. Open Chat → DingDong → Group Chat → New Chat.
2. Enter Room Name, up to 40 characters. Correct any inline error.
3. Search by the displayed name or type label, then tap bot rows. Cobelly cannot be selected. Selected bots stay selected outside the search result.
4. Tap Create. Fields, selection and Back are disabled until the request finishes. Success opens the room; failure keeps the draft and shows a message.
5. Use Back before submitting. If a draft or search remains, Cancel keeps editing and Discard leaves without saving. An unchanged blank screen leaves directly.

## Limits and recovery

At least one selected bot and a normal signed-in account are required. Preview cannot create a room. You are the only human participant. There is no separate type filter or list Refresh/Retry in these creation screens.

Desktop fields remain editable while creation is pending; those edits do not change the already submitted request. Mobile blocks leaving during creation. Neither platform automatically saves a draft when leaving.

Choose an available owned DingDong. If a selected bot is no longer available, reopen the list and select again. Clear search before assuming the list is empty. Create a Pure first if you have no selectable bots.
