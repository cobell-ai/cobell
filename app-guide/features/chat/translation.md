# Translate or rewrite displayed messages

Configure a display transformation and switch between the original and transformed text.

## Start here

**Desktop:** Chat panel → open the room → composer → Translate / Rewrite, then the language or rewrite setup controls.

**Mobile:** Use Translate/Rewrite beside the composer and its configuration panel.

## Desktop steps

1. Open Translate / Rewrite from the composer.
2. Choose Translate and a target language, or Rewrite and explicit requirements.
3. Add Translation memory if needed and Confirm.
4. Set whether your own messages should be transformed.
5. Use each bubble’s display controls to compare with the original.

## Mobile steps

1. Open the Translate/Rewrite panel.
2. For Translate, choose Translation language. For Rewrite, supply Rewrite requirements.
3. Set Translation Memory and the own-message toggle as needed.
4. Enable the mode and use bubble controls to view original or transformed content.

## Completion, limits and recovery

The mode automatically processes eligible text messages as the conversation loads and new messages arrive. It changes only your view, preserving originals and other participants' displays. Files, system events and actively streaming AI responses are not transformed. The own-message toggle controls inclusion of your sent messages.

Rewrite follows your prompt. For example, request key points, a different tone or only tasks assigned to you, with a dot for messages containing no such tasks. These are user-written instructions, not fixed modes. A target language is required for Translate; explicit requirements are required for Rewrite.
