# Create, navigate and close threads

Keep a side conversation in a nested thread.

## Start here

**Desktop:** Enable Create thread in the composer; click a thread-root bubble to open it.

**Mobile:** Enable Thread near the composer; tap the thread-root bubble to open it.

## Desktop steps

1. Enable Create thread and send the root content.
2. Click the resulting thread bubble to enter.
3. Send replies within that thread and use Back to return.
4. To close your thread, open an eligible message inside it → More/right-click → Close thread (convert message), then review the replacement and confirmation. Use the root bubble's menu for Delete thread.

## Mobile steps

1. Enable Thread in the composer and send.
2. Wait for the root's send to be confirmed, then tap the thread bubble or Open thread. Pending and failed cards cannot be opened.
3. Use Back to return to its parent.
4. To close your thread with a selected message, open that message's More menu → Close thread and confirm. The root bubble also offers closure when its original content is eligible, and Delete thread for removal.

The mobile card's author, reply count and latest reply are previews within its Open thread target. AI cannot see this thread is a read-only card label. In a read-only view, the card can still open after confirmation, but Thread actions is unavailable.

In the mobile Close thread dialog, read the warning and read-only replacement preview, then choose Close thread or Cancel. Delete thread has a separate confirmation. Canceling or dismissing keeps the thread unchanged. After a failure, inspect the current thread before repeating the action.

For a pending mobile thread root, the spinner appears immediately. A failed root uses the [failed-send controls](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/chat/send-reply.md): Try again when eligible, or Delete message to remove the failed local entry. This is separate from deleting a confirmed thread through Thread actions.

## Completion, limits and recovery

Threads can nest up to five levels deep; the main chat does not count toward this limit. At maximum depth, return to a parent before creating another thread. Only the thread creator can close it, using eligible confirmed content from the same thread. Recipient-filtered content cannot be used as the replacement. Closure is permanent and replaces the root; deletion removes the thread. Thread creation and Hidden composer mode are mutually exclusive.
