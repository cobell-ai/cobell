# Send messages, mentions and replies

Write a normal message or reply to a particular message.

## Start here

**Desktop:** Open the room from the chat panel and use its bottom composer.

**Mobile:** Open the room from Chat and use the bottom composer.

## Desktop steps

1. Open the room and type in the bottom input.
2. Choose a mention suggestion if addressing a participant.
3. Use a message’s right-click/More → Reply to respond with a linked preview.
4. Check the recipient and thread modes, then Send.

## Mobile steps

1. Open the room and type in the bottom composer.
2. Use mention suggestions if needed.
3. Open a message’s More menu → Reply.
4. Review its composer preview and send.

## Completion, limits and recovery

A pending message can show a progress indicator. Wait for the send result before treating it as sent.

For a failed message, use Resend on desktop or Try again on mobile when offered. Wait for the result before repeating. Retry requires the room to allow sending; unavailable or read-only rooms can restrict it. If retry does not proceed, reopen the room and check the current message and sending status. Mobile P2P file offers do not use this message retry.

Use Delete on desktop or Delete message on mobile to discard a failed local entry without confirmation. This does not retract a copy that reached the service. Removing a failed P2P offer can also cancel its local transfer. Deleting a confirmed message from its More menu is a separate action.

Closed rooms and closed threads do not allow new messages. A failed message can remain visible without a retry action. Messages sent on your behalf by Cobelly carry a corresponding marker.
