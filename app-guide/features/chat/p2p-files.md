# Transfer a file with a P2P offer

Use a direct device transfer and track each recipient’s acceptance.

## Start here

**Desktop:** Chat panel → open the room → composer → Send P2P file.

**Mobile:** Received P2P offer cards provide Accept and Reject; use desktop to originate a P2P file offer.

## Desktop steps

1. Use Send P2P file and select the file and recipients through the offered flow.
2. Wait for the recipients to accept on their eligible devices.
3. Watch the per-peer status for completion or failure.

## Mobile steps

1. Open the received P2P offer in the chat.
2. Confirm it is for this device and is not expired.
3. Choose Accept or Reject and watch the transfer status.

## Completion, limits and recovery

Acceptance alone is not transfer completion. Expired or device-ineligible offers cannot be treated as ordinary attachments. Receiver failures offer retry where available.
