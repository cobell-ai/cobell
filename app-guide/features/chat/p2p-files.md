# Transfer a file with a P2P offer

Send a file as a transfer offer and track the recipient’s acceptance.

## Start here

**Desktop:** Chat panel → open the room → composer → Send P2P file.

**Mobile:** Open the chat → composer → More → Send P2P file, when available.

## Desktop steps

1. Use Send P2P file and select the file and recipients through the offered flow.
2. Wait for the recipients to accept on their eligible devices.
3. Watch the per-peer status for completion or failure.

## Mobile steps

1. To send, choose **Send P2P file**, pick the local file, and wait for the recipient to accept.
2. To receive, open the offer on the intended device while it is still active.
3. Choose **Accept** or **Reject** and check the transfer status.

## Completion, limits and recovery

Keep both devices connected and the original file available until the transfer shows completion. Receiver failures offer retry where available.
