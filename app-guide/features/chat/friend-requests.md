# Send and handle friend requests

Add a person using their Cobell ID or discoverable email and review incoming requests.

## Start here

**Desktop:** Click your avatar/name near the upper-right → Profile → Friend, or use Fr → Friends → Add Friend in the chat panel. The panel action starts at Inbox; use Send Request to send a new request.

**Mobile:** Home → Friends → Add friend, or Profile → Friends and its management action.

## Desktop steps

1. Open Profile → Friend → Send Request.
2. Enter the person’s Cobell ID or email.
3. Send the request and check the result.
4. For incoming requests, use Inbox, then Accept or Reject.

## Mobile steps

1. Open Friends and Add friend.
2. Use Send, enter one Cobell ID or email and tap Send friend request.
3. Use Inbox to Accept or Reject incoming requests.
4. Refresh if the list failed to load.

## Completion, limits and recovery

The recipient must enable discovery for the chosen identifier. A sent request is not yet a friendship. A failure retains the input for correction or retry.
