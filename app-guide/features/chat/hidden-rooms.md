# Restore a hidden chat

Bring a room back to the ordinary chat list.

## Start here

**Desktop:** Click your avatar/name near the upper-right → Profile → Chat → Hidden chats.

**Mobile:** Chat → header's Hidden chats eye button. More → profile card → Hidden chats opens the same sheet.

## Desktop steps

1. Open Profile → Chat → Hidden chats.
2. Find the room and choose Unhide.
3. Return to the chat list and open it.

## Mobile steps

1. In Chat, tap the Hidden chats eye button in the header, or open More → profile card → Hidden chats.
2. Scroll to the room and check its name, type and preview. Tap Unhide; tapping the row body or avatar does not open the room.
3. Wait for that row's progress to finish. For an uncertain visibility result, use Check status instead. It checks the earlier result without sending another hide/unhide request.
4. If an inline error appears, inspect the current status before trying its action again. A failed directory load has a separate Retry, possibly above retained rows. An ordinary empty list says No hidden chat rooms.
5. Close or dismiss the sheet, return to Chat and open the restored room. Restoration does not navigate into it automatically.

The mobile sheet includes supported non-group rooms and excludes Cobelly and Flow. Unhiding a room with blocked remote access brings back this device's local history without restoring remote membership or access. Use Check status for an uncertain visibility change.

Use a normal signed-in account; preview and agent sessions cannot open the sheet. Reopen current controls after account or access changes. Dismissing the sheet does not undo an accepted visibility change.

## Completion, limits and recovery

Hidden Chat Rooms is separate from messages hidden from AI. Restoring room visibility does not reopen a room that was permanently closed.

Also find this under: unhide chat, missing room, archived room, hidden list.
