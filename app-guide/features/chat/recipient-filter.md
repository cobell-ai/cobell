# Choose who receives a message

Set explicit recipients or exclusions before sending.

## Start here

**Desktop:** Use Recipient filter near the composer; open the recipient badge on a sent message to inspect it.

**Mobile:** Use the composer Recipient filter action, including More when compact. Tap a message's recipient badge to inspect its stored audience.

## Desktop steps

1. Open Recipient filter before sending.
2. Choose Only to or Except and select the intended participants, or Only me.
3. Resolve any unavailable selections.
4. Click Apply and review the composer’s filter indicator before sending.

## Mobile steps

1. Open the composer’s Recipient filter action.
2. Choose Only to, Except, or Only me.
3. Select recipients and resolve unavailable entries.
4. Tap Apply and review the active filter before sending.

## Completion, limits and recovery

To inspect a sent message, open its recipient badge. Desktop opens Specified recipients or Excluded users; scroll the list and use Confirm to close. Mobile opens a scrollable sheet; use Close to leave. Names and rows are read-only and do not open profiles or change recipients.

The badge counts stored selected or excluded people, including those whose current participant details are unavailable. Me means only the current account is explicitly selected. An exclusion count counts excluded people, not the allowed audience. Unavailable people appear as a grouped count and remain part of the rule.

Messages with recipient filters are excluded from AI context. An exclusion policy can allow people invited later to see the message; use explicit recipients if that is not intended. Sent-message lists describe the saved audience rule, not delivery or read receipts. They do not reconstruct everyone who received an older exclusion-based message.
