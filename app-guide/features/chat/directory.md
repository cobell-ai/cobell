# Find, pin and organize chats

Find an existing room or friend and keep frequently used entries easy to reach.

## Start here

**Desktop:** Use the chat panel’s All, DD (DingDong) and Fr (Friend) tabs.

**Mobile:** Use Chat, the second bottom tab; Home also has Friends and DingDongs lists.

## Desktop steps

1. Select All, DD or Fr in the chat panel.
2. Use the corresponding list/direct/group filter. In All, open name search with the header magnifying glass or Left Ctrl+F.
3. Click the room row to open it. In a human-only direct room, its avatar opens the other person's profile; a single-DingDong room opens its bot profile when resolvable. Other avatars open participants.
4. Use its pin control or right-click Pin to top.
5. In All, pin at least two visible entries, then drag Reorder pinned item to change their order.
6. Clear search with the backspace-shaped icon, or close and clear it with Close or Esc. Changing the main directory tab also clears All search.
7. In All, use the row gear for DingDong settings, or right-click → Chat room settings for room controls. Back or Esc returns to the directory.

In Fr, choose Friends for people or Direct/Group for rooms. A person's row opens their profile after checking friendship; choosing a chat from that profile switches to Direct and opens it. Friends → Add Friend opens Inbox. Use Direct → New Chat or Group → New Chat to create a room; the creation guide distinguishes their submission steps.

Fr's search magnifying glass clears the query when closing the field. Its Friends/Direct/Group subfilters keep the query, so clear it when changing what you are looking for. Ctrl+F opens search. Refresh is available in Friends; a failed friend-list read also has Retry.

In DD, List shows owned bots: click the row for its first listed chat, or its own chat when available, and the avatar for its profile. Direct shows single-DingDong rooms and Group shows DingDong groups. List → plus creates a Pure; Group → plus opens group creation. List Refresh reloads owned bots. DD's magnifying glass can hide search while keeping its filter; clear, Close or Esc removes the query. List searches names/type labels; Direct/Group search room names. Left Ctrl+F opens search, and subfilter changes retain the query.

## Mobile steps

1. Tap Chat and choose All, DingDong or Friends. Under Friends, choose Friends for people or Direct Chat / Group Chat for rooms. Under DingDong, choose DingDong list, Direct Chat or Group Chat.
2. Type in Search chats. Room lists match names or displayed message previews; Friends matches names; DingDong list matches names or type labels. Filters retain the query, so use clear to remove it.
3. Tap a room's body to open the conversation. A single-DingDong avatar opens its bot profile. In a human-only direct room, the avatar opens the sole counterpart's profile; other avatars open participants. A Friends row checks friendship and opens that person's profile.
4. Swipe a room right for settings and pin actions, or left for Open, eligible Mark as read and Leave chat. These directions apply to English/Korean layouts. Tap a revealed button; swiping itself does not run it. Tap the row or outside it to close the rail.
5. Alternatively, long-press the room or tap its more button to open the available actions. To leave, choose Leave chat, review the room name and confirm, or Cancel.
6. Pin rooms with Pin to top. Friends and DingDong list have separate pin buttons. With at least two visible pins, use Reorder pinned item and choose Move up among pinned items / Move down among pinned items. A room's more sheet also offers those moves.
7. In Friends → Friends, Add Friend opens Send Request. In DingDong list, Add DingDong opens Pure creation. New Chat starts friend creation from All or Friends → Direct/Group, and DingDong group creation from DingDong → Group Chat. DingDong → Direct Chat has no creation button.
8. Use Refresh in Friends → Friends or DingDong list to reload the directory. The header's Hidden chats button opens hidden rooms; Pending chat changes lists unfinished exits or local cleanup. Selecting an idle pending row opens its settings. Home's Friends and DingDongs lists are additional entry points.

On mobile, room search ignores surrounding spaces and letter case. It searches the displayed preview, not full message history. Use the available type chips to filter DingDong Direct Chat results.

Mobile keeps separate room pin orders for All, friend Direct/Group and DingDong Direct/Group. Friends and the DingDong list have their own pins. Reorder visible pinned results and check the displayed order after saving. If saving fails, use the offered Retry and confirm the result.

Mobile Leave chat is unavailable for Cobelly, blocked or unsupported rooms and group representatives. If leaving is uncertain, use Check status; use Retry when cleanup is offered. Reopen current room controls after account or access changes. Use a load-error Retry when shown; an empty search result alone does not mean loading failed.

## Mobile full lists from Home

1. In Home, choose See all beside Friends or DingDongs. This opens the people/bot list, without Chat's Direct/Group room filters.
2. Type part of a friend's name, or a bot name/type label. Search ignores case and surrounding spaces. Delete its text to clear it; no separate clear button is provided here.
3. Tap a friend for their profile. For a bot, tap the body for its conversation or the avatar for its profile.
4. Use the pin button or, with two visible pins, the swap-arrows menu's available up/down moves. These share the friend/bot pin order used by Home and Chat's corresponding list.
5. Refresh with the header icon or pull down, including on an empty list. A failed read offers Retry, possibly above retained rows. Refresh/Retry keep search and are disabled while busy. Clear the query before assuming there are no entries.
6. Use the header plus to open Send Request for a friend or Pure creation for a DingDong. Back returns to the previous screen, with Home as the fallback.

## Completion, limits and recovery

Pinned order is scoped to the corresponding directory. If saving the order fails, use its retry control. A closed or blocked direct chat can remain available as local read-only history.

Desktop All search matches displayed room names without case sensitivity. The header magnifying glass only hides or shows the field: its query still filters rooms while hidden. Use clear, Close or Esc to remove the filter. Hover DD or Fr to read its full name; scroll the header horizontally if its tabs do not fit.

Desktop All has no list-selection mode. If No chat rooms appears while searching, clear the query to check the complete directory. If initial loading fails before any rooms are available, Could not load chat rooms offers Retry to restart directory initialization. Loading progress itself has no button; an individual room's recovery action is separate.

In desktop All, pinned entries come first; other rooms follow latest-message order. Reorder the visible pins and check the resulting order. If saving fails, use the current notice's Retry or reopen the list before trying again.

On desktop, Friend and DingDong subdirectories keep separate pin order. Reordering requires at least two visible pins. Their room directories have no list-selection mode. Normal account sign-in is required. Friends can show an error with Retry; Direct/Group may show an empty list while data is loading or unavailable. Clear search and check current availability before interpreting an empty list as no rooms.
