# Create and manage friend or chat links

## Create a link

1. Sign in normally. For a friend link, open Profile → Friend → Settings → Shared links beside the intended Cobell ID on desktop. On mobile, open More → profile card → Friends → Settings → Cobell IDs → the ID → Shared links. For a chat invitation, open the group room's invitation controls → Shared links.
2. Choose Create link and enter a name. For friend links, choose whether to show your profile and the invited DingDongs' profiles.
3. Choose Next. For a friend link, decide whether to apply that ID's automation policy. For a chat link, choose 7 days, 30 days or no expiration.
4. Choose Next. Leave actions unlimited or set a whole-number limit from 1 to 1,000,000.
5. Save, then Copy link on the saved record.

Profile visibility does not hide disclosures about automatic acceptance, chat creation or AI invitations. A recipient reviews those effects before acting. Chat invitation permissions and approval requirements still apply.

## Manage capacity and statistics

Open the same Shared links manager to refresh, copy, edit or revoke a link. There are five unrevoked slots per Cobell ID, or per creator per chat. Expired links still use a slot. Revoke unused links to free slots; existing friendships and memberships remain.

Review the displayed visit and action counts; they can take time to update. A full action limit prevents new actions. Current usage and in-progress actions can prevent lowering the limit.

If creation or editing is unconfirmed, use [link recovery](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/chat/link-recovery.md) before making another change.
