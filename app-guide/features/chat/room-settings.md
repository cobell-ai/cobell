# Open room settings and participant profiles

Find room controls and distinguish them from each DingDong’s settings.

## Start here

**Desktop:** In the chat panel's All directory, right-click the room row → Chat room settings. The row's gear starts at DingDong settings; use its header switch for Chat room settings.

**Mobile:** Open the room and tap the upper-right gear icon.

## Desktop steps

1. In All, right-click the room row and select Chat room settings. The row gear instead opens DingDong settings.
2. Use Participants to inspect people or bots.
3. Choose the needed name, notice, invitation or room-management control.
4. Use DingDong Settings when configuring an owned bot, rather than the room itself.
5. Use the header's chat-bubble or robot button to switch configuration views. Back or Esc returns to the directory.

## Mobile steps

1. Open the chat room and tap the top-right gear.
2. Use People and DingDongs to open participant profiles.
3. Choose the required Room, Roles or Danger Zone item.
4. Use DingDong Settings for owned bot behavior.

## Completion, limits and recovery

Ownership, room type and participation role determine which controls exist. Closed rooms show a read-only local-history view with Remove Chat Room; normal server mutations are not available there.

On desktop, a human-only direct room's avatar opens its single counterpart's profile. A single-DingDong room opens its bot profile when the target is available. Other cases open participants, where individual profiles may be available.

Also find this under: room settings, participants, gear icon, chat configuration.
