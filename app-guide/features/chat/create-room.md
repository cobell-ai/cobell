# Create a direct or group chat

Start a new conversation with friends or an owner-only DingDong group.

## Start here

**Desktop:** Fr → Direct or Group → plus (New Chat). DD → Group → plus creates an owner-only DingDong group. DD → List → plus creates a DingDong instead.

**Mobile:** Chat → Friends → Direct or Group → New Chat. For bots, use Chat → DingDong → Group Chat → New Chat.

## Desktop steps

1. For a direct room, choose Fr → Direct → plus. Search if needed, then click the friend. That click immediately requests the new room; there is no later Create step.
2. For a group, choose Fr → Group → plus. Enter Room Name and select friends. Search filters visible rows without removing existing selections; check the total count.
3. Click Create. If Invitation approval needed appears, review who joins first and who needs a vote. Choose Create and request votes to continue, or Cancel to return to the draft.
4. For an owner-only AI group, choose DD → Group → plus and select owned Pure DingDongs. DD → List → plus creates a bot rather than a room.
5. Before submitting desktop friend creation, Back or Esc leaves without saving the draft or asking Save/Discard. If you opened group creation from a person's profile, that preselected person cannot be removed.

## Mobile steps

1. Open Chat → Friends → Direct or Group → New Chat.
2. For a direct friend chat, tap the friend's row to request creation immediately. There is no later Create step.
3. For a group, enter its name, select people and tap Create. If an approval plan appears, review it and choose Create and request votes to continue, or Cancel to keep the draft.
4. Alternatively choose DingDong group creation, name it, select owned DingDongs and Create.
5. To return before creating, use Back. If you changed the mode, name, search or selection, choose Cancel to keep editing or Discard to leave without saving. Leaving is blocked while a creation request is running.

## Completion, limits and recovery

Friend direct rooms require an explicit friendship. Some group participants require approval votes. If the room is created but votes fail to start, invite the remaining people through room settings. Cobelly cannot be invited into another room.

Desktop friend creation keeps the name and selections after a failure. Correct a validation error or dismiss its explanation with Confirm. Group Create requires a selected friend and is disabled with progress while submitting. The sent request uses the name and participants captured at submission. Leaving the view does not cancel it; inspect existing rooms and current participants before repeating an uncertain creation.

On mobile, switching New Group Chat clears selected people; switching it off also clears the name. Search changes retain selected people outside the result. Room Name is limited to 40 characters. Correct its inline error before resubmitting. Name, search, switches, candidate rows and Back are disabled during creation. In a short view or with the keyboard open, scroll the controls above the candidate list.

If mobile selection loading fails, use Retry. A creation failure retains the draft and shows a message. Use a normal account; preview cannot create a room. Reopen the current screen after account changes.

After mobile group creation, an invitation-failure banner's Retry resends the stored invitations for the existing room. It does not create a new room. Wait for progress and check participants/votes after an uncertain result; a completed invitation is not an approved vote.
