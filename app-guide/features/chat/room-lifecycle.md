# Hide, leave, close or clear a chat

Choose the room operation whose effect matches your goal.

## Start here

**Desktop:** Chat panel → right-click the room row → Chat Room Settings → the bottom room actions.

**Mobile:** Second bottom tab Chat → open the room → gear → Danger Zone.

## Desktop steps

1. Open Chat Room Settings.
2. Choose Delete Data, Hide Chat Room, Leave Chat Room or Close Chat Room according to the desired effect.
3. Read and confirm the action.
4. For a closed local-history room, use Remove Chat Room to remove only this device’s copy.

## Mobile steps

1. Open the room settings → Danger Zone.
2. Choose Delete Chat Data, Hide Chat Room, Leave chat or Close Chat Room.
3. Review and confirm the specific effect.
4. If the result is uncertain, use Check status before issuing another change.
5. Use Remove Chat Room only for removing the closed local copy.

To leave from the mobile list, swipe the room left in an English/Korean layout, long-press it or tap its more button. Choose Leave chat, review the displayed room name, then confirm or Cancel. The action is unavailable for Cobelly, blocked or unsupported rooms and group representatives, and requires an active group participant. If the result is uncertain, Check status opens room settings; if only local cleanup remains, Retry repeats cleanup. A generic failure notice alone does not establish that leaving succeeded.

## Completion, limits and recovery

Clearing data does not stop new messages. Hiding is reversible through Hidden Chats. Leaving can require an invitation to rejoin. Closing is for everyone; saved history becomes read only. Do not treat these controls as interchangeable.
