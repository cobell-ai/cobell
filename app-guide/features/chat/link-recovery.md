# Resolve an unconfirmed link action

## Creating, editing or revoking

1. Read the recovery message. Do not treat a timeout as a confirmed failure or success.
2. If the editor is read-only, choose Back to links.
3. Use Check status or Refresh as offered and inspect the current records.
4. If manual review is required, verify the intended record and its options before choosing I've reviewed the links. Acknowledgment unlocks further work; it is not a success receipt.
5. Only then decide whether another change is necessary. A similar link may have been created by a different request.

## Sending a friend request or joining

1. Keep the original received-link screen open.
2. Use Check status. The disabled submit button prevents sending the unresolved request again.
3. For a confirmed success with stale local data, use desktop Refresh account or mobile Refresh data, then continue to the destination when offered.
4. If the app says the previous participation is no longer active, do not interpret it as a new successful join.
