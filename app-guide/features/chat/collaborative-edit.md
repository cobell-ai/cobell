# Edit a message collaboratively

Join a supported co-edit session and distinguish saving, leaving and ending it.

## Start here

**Desktop:** Message More/right-click → Co-edit or Join co-edit; a Co-editing indicator also opens the session.

**Mobile:** Message More → Collaborative edit, or tap the collaborative-edit indicator.

## Desktop steps

1. Open an eligible message’s More menu → Co-edit or Join co-edit.
2. Edit in the collaboration dialog and watch connection status.
3. Save the content.
4. Choose Leave to stop participating or End to finish the session when authorized.

## Mobile steps

1. Choose Collaborative edit on a supported message.
2. Join the editor and make changes.
3. Use its save control and read any persistence error.
4. Leave or end using the offered session actions.

## Completion, limits and recovery

Connection errors and save errors are separate. Leaving a session is not equivalent to ending it for everyone. Ordinary Edit and Co-edit are different message operations.
