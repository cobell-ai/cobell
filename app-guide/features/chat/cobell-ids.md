# Manage Cobell IDs and friend discovery

Create an identifier other people can use and control who may request friendship.

## Start here

**Desktop:** Click your avatar/name near the upper-right → Profile → Friend → Settings.

**Mobile:** Friends management → Settings → Cobell IDs.

## Desktop steps

1. Open Profile → Friend → Settings.
2. Enter an identifier in Create Cobell ID and create it.
3. Set email, phone and ID discovery switches as needed.
4. Configure Auto accept and Auto-create chat for that ID.
5. Review the limits before deleting or replacing an ID.

## Mobile steps

1. Open Friends management → Settings.
2. Tap Create under Cobell IDs and enter the identifier.
3. Open an ID to edit its Active, automatic acceptance and chat settings, then Save.
4. Use the account discovery switches for email or phone visibility.

## Completion, limits and recovery

Cobell IDs use letters, numbers, underscores, dots or hyphens and have current-held and yearly-creation limits. Deleting an ID does not replenish the creation allowance. Phone discovery can reflect an already registered phone, but the current mobile version says phone registration is unavailable.

Also find this under: friend request ID, discoverability, automatic accept, phone number.
