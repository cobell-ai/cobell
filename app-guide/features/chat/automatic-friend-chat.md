# Configure automatically created friend chats

Choose the room-name template and DingDongs used when a Cobell ID creates a chat.

## Start here

**Desktop:** Click your avatar/name near the upper-right → Profile → Friend → Settings → the Cobell ID’s automatic chat controls.

**Mobile:** Friends management → Settings → select the ID → Automatic chat DingDongs and Gears.

## Desktop steps

1. Open the Cobell ID settings and enable Auto-create chat.
2. Edit the room-name template; use Insert variable for the requester name, creation time or short code.
3. Add DingDong and select its Gear.
4. Set its behavior and save the offered controls.

## Mobile steps

1. Open the Cobell ID and enable Automatically create a chat.
2. Edit Chat room name template and Insert variable as needed.
3. Open Automatic chat DingDongs and Gears → Add DingDong.
4. Choose the DingDong and Gear, edit its behavior and save.

## Completion, limits and recovery

Final room names are limited to 40 characters and variable expansion can be shortened. Put must-keep text first. A DingDong’s new shared chat invite policy can prevent automatic participation; existing chats are not retroactively changed.

Also find this under: automatic chat, requesterName, createdAt, shortCode, auto invite.
