# Create a Pure DingDong

Create an owned agent and its personal chat, then equip compatible Pure Gear.

## Start here

**Desktop:** Management → Pure → Add in the collection header, or Create New Pure in an empty list.

**Mobile:** Third bottom tab Shortcuts → DingDong → DingDong collection → Create. Home/Friends DingDong directories also offer Pure creation.

## Desktop steps

1. Open Create Pure and enter a 1–40-character Name using supported letters, numbers and underscores. Check the field error if the name is not accepted.
2. Click Create or press Enter. Create is disabled for an empty or invalid name. Inline validation can appear after a delay; Enter forces the current feedback.
3. Wait for creation. The list can show a temporary entry before the server result. A successful result closes creation and opens Set up DingDong Gear.
4. Select compatible Gear and Save. If none exists, use Create Gear, finish creating it, return and select it. Creating Gear alone does not equip it.
5. Open the DingDong's personal chat and check its Gear before using the Bell.

## Mobile steps

1. Open Create and enter Name with the same identity rules above. Use Create or the keyboard's Done action. An invalid name is reported when submitting; Create need not be disabled beforehand.
2. Wait while Creating is shown. Name editing, repeated submission and Back are blocked during this request.
3. Success opens the new DingDong's management detail.
4. In Overview, tap Choose Gear, select compatible private Pure Gear and Save. Alternatively, open the personal chat and complete its missing-Gear setup.
5. Open the personal conversation after setup and make a small request.

## Cancel, failure and uncertain results

- Desktop Cancel, the close icon or dismissing the creation dialog before submission abandons the name without confirmation. During submission, Cancel and Create are disabled, but the close icon and dialog dismissal remain available. Closing does not cancel a request already sent; Gear setup may not open afterward.
- Mobile Back with a nonblank draft opens Discard changes? Cancel keeps the form; Discard leaves without creating it. Whitespace-only input does not trigger that draft confirmation. Back is blocked while Creating.
- Desktop creation failure keeps the dialog/name and shows a failure message; a temporary list item is rolled back. Mobile failure keeps the form/name and shows an error below it. Correct invalid input or refresh the collection before deciding to submit again.
- A lost response or dismissed pending dialog can leave a created DingDong on the server. Refresh the collection and inspect its personal chat before repeating Create. A temporary entry or spinner alone is not confirmation.
- Closing the later Gear setup does not delete the created DingDong. Reopen Choose Gear or the personal chat instead of creating another bot.

Pure creation asks for a name only. Put role instructions in a Memory attached to Gear, and reference files in KnowledgeBox. Cobelly already belongs to the account and is not created here. After an account change, reopen creation from the current account rather than using an old form.
