# Inspect a DingDong and manage its image

Inspect the bot in a selected chat, open owner settings and review its current image.

## Start here

**Desktop:** Open a bot avatar in a chat, or the profile control in Management → Pure. The Management entry starts with the bot's chat list.

**Mobile:** Open the bot's participant profile from a chat, or use its management detail's Open profile action. Use a normal signed-in account; preview content does not authorize profile actions.

## Desktop steps

1. From the Management profile, select a chat row. This changes the profile's room context; it does not open the conversation. Use the header Back arrow to return to the list.
2. Check the selected room. For another owner's bot, Public configuration is read-only. For your bot in a shared room, Visible to everyone shows the summary and Visible only to you contains its settings. Your personal bot chat shows the settings panel directly.
3. Review Active, Bell permission, intelligence and automatic reply, including delay. Mode is omitted for Cobelly. Without a selected room, fallback values are not confirmation of a particular room's saved settings.
4. To change your bot's behavior or Gear, use the embedded settings panel. The bot selection is locked to this profile; follow the linked settings guides for saving and recovery.
5. The Owner row displays the human owner's name and avatar. It is not a link to their profile.

The list shows related chats available to the current account and may not include every room containing the bot. Reopen or use Retry if it looks incomplete. Retry refreshes the list without sending an invitation or message.

## Mobile steps

1. Read the bot's name, avatar and, in a chat, its joining date and public configuration.
2. The configuration card shows Enabled, Mode, Auto Reply, Delay and Bell permission. It does not show an intelligence row. Use your bot's DingDong settings action when available to change its configuration.
3. Under Chats with this DingDong, select another chat to open the same bot's profile in that room. Then use Open chat to open the conversation. The current room is excluded from this list.
4. Choose an available chat containing this DingDong. A Hidden chats label does not restore the room to the chat list. Use Retry if the list cannot be read.
5. Participants opens the current room's participant list. DingDong management opens the owned bot's management detail when available.

The mobile bot profile has no Owner row that opens a human profile. Its Block, Unblock and friendship Remove actions target the human owner. Friendship Remove does not remove the bot from the room.

## Images

View Image on desktop or View larger on mobile opens the current avatar. On mobile, pinch to zoom and drag to move; use Back to return. Only the owner can manage the image of a supported owned bot.

Follow [DingDong profile images](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/dingdongs/avatar-generation.md) for style/reference/prompt inputs, generation status, candidate review, application, retry and image removal. Generation can use the bot's name, personal-room Gear Memories and selected options.

## Safety and removal

Use [room removal](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/dingdongs/remove-from-room.md) for Remove DingDong, Kick Owner and the mobile participant menu. Blocking the owner, removing one room participant and deleting an owned Pure are different actions.

If a scoped profile becomes unavailable, return to your current chat or management list and reopen it. After changing accounts or losing room access, reopen from the current account before acting.
