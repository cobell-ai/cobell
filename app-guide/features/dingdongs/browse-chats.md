# Browse a DingDong's chats

Find a room the bot participates in, open its conversation or adjust that room's DingDong settings.

## Desktop steps

1. Open Management → Pure → your DingDong → Chat. With no explicit selection, the content area uses its personal chat.
2. Use All, DD or Gen above the list. The selected label expands to DingDong or General. General contains friend direct and group chats. Filters change the displayed subset.
3. Outside Edit, click a row to select it. If a shared-room selection leaves the content asking you to select a chat room, open that room through the main chat panel. The personal row's pin is fixed in this management list.
4. To change the bot's behavior for a room, use that row's settings gear. Back or Esc returns to the list. The visible right-click settings items currently do nothing in this management list; use the gear instead. The avatar opens a separate profile/participant view.
5. Use Join, or Join general chat room in an empty General section, to choose existing rooms. This opens selection without sending an invitation. In Edit, click an eligible row or its checkbox to toggle removal selection; the fixed personal chat cannot be selected. Avatars, row gears and pin controls are hidden or inactive in this mode.

After a refresh error, use the offered Retry or reopen the list or selected room. Refreshing does not resend messages or repeat a join or removal.

Use the profile header's Chat and K-Box buttons to switch panels, or its Back arrow to return to Management. Save file changes first; these actions do not run the resource-tab Save/Discard/Cancel check. Esc in Edit clears removal selection, but does not undo a request already sent. If the DingDong is not found, its Back arrow returns to Management; that state has no Retry button.

## Mobile steps

1. Open Shortcuts → DingDong → your Pure → Chats.
2. Tap a row to open its chat screen. You can also use the row's swipe action or long-press → Open. If the swipe rail is revealed, tapping the row closes the rail first; tap again to open. Dismiss the action menu to stay in the list.
3. Use Join chats to add the owned bot to existing rooms. Normal ownership is required; preview and agent login do not offer joining. Use the invitation-policy control to allow or prevent new shared-chat invitations.

Mobile opens rooms directly. Its managed Chats tab does not have the desktop All/DD/Gen filters or removal-selection mode. An empty list can still offer Join chats when the account and bot are eligible.

## Completion and recovery

Selecting a row does not join it, and a listed room does not confirm a pending membership change. Check current participants after an uncertain invitation or removal. Follow the join/removal guide before submitting again. Access changes may leave a room unavailable or read-only.

Also find this under: management chats, bot conversations, General filter, room settings gear, cannot select chat, refresh room details.
