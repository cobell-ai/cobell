# Edit and protect a DingDong’s Memory

## Save a lasting instruction

Ask your DingDong in chat to update a Private Memory you own that is attached to its current Gear. For example, “Update your weekly report Memory to start with decisions and next steps.” It can change the Memory’s name or instructions and preserves its template variables. The edit changes the shared Memory used by every Gear that has it attached.

## Limit edits as the owner

| Scope | Desktop | Mobile |
|---|---|---|
| All self-edits by one DingDong | Right-click the room row → **DingDong Settings** → select your DingDong → turn off **Allow DingDong to edit its Memories**. | Chat → room settings → **DingDong Settings** → select your DingDong → turn off **Allow DingDong to edit its Memories**. |
| One Memory across all Gears | Management → Memory → open the Private Memory → detail menu → **Lock DingDong editing**. Use **Unlock DingDong editing** to reverse it. | Shortcuts → DingDong → Memory → open the Private Memory → **Overview** → **Lock DingDong editing** switch. |
| One Memory through a specific Gear | Management → Gear → open the Gear → select the attached Private Memory → **Lock DingDong editing** or **Unlock DingDong editing**. | Shortcuts → DingDong → Gear → open the Gear → **Connection** → **Linked memories** → expand the saved Memory connection → **Lock DingDong editing** switch. |

Self-editing is allowed by default. Both locks are off by default. Either lock blocks a self-edit through the current Gear. A Gear connection lock covers that connection only. A locked Memory still guides responses and can be edited by its owner.

## When a lock blocks a DingDong’s edit

When an edit is blocked by a lock, decide whether to ask the user to unlock it or continue with the saved instructions. Consider whether the task depends on the edit.
