# Equip a DingDong with Gear

Assign compatible Gear to one of your DingDongs in the current room. Creating Gear and equipping it are separate steps.

## Start here

**Desktop:** Right-click the room row → DingDong Settings. An unconfigured personal chat or settings view shows Set up DingDong Gear.

**Mobile:** Open the personal chat's Select Gear action, or room settings → DingDong Settings. If the personal chat has no compatible Gear, start with Create Gear.

## Change an existing assignment

1. Open DingDong Settings in the target room. If it contains several owned DingDongs, select the intended one. Other people's DingDongs are not configurable here.
2. In a shared room, turn Active on (desktop) or Enabled on (mobile) if the settings below it are disabled.
3. Desktop: click the current Gear name or Select beside Gear in use. Choose one row, then Select to start saving. Cancel abandons the choice. The selection dialog has no creation or refresh control; create new Gear through management first.
4. Mobile: choose a different entry in the Gear dropdown. This starts saving immediately; do not look for a separate Save button.
5. Check the displayed Gear after saving settles. An immediate display change can precede the server result. On failure, confirmed settings can return; mobile's Retry error action reads saved settings rather than repeating the assignment request.

## Complete missing setup

1. Open the personal chat's setup action or DingDong Settings → Select Gear on mobile. Desktop shows the setup panel directly when needed.
2. Wait for the setup check. If loading fails, use Retry before treating the list as empty. Desktop's catalog-error Retry also refreshes Gear information.
3. Choose Gear with the same DingDong type. Mobile offers your own private Gear. The current valid assignment or first available entry can already be selected; this is still an unsaved choice.
4. If none exists, choose Create Gear, create a compatible configuration and return. Review the refreshed list and select the intended Gear; creating it does not equip it automatically.
5. Press Save. Save and Create Gear are disabled while submitting; mobile also disables the candidate rows. Desktop shows Gear saved and refreshes setup. Mobile returns after an acknowledged save.
6. Confirm the personal conversation or settings now opens with the expected assignment. If saving fails, the setup screen stays open. Recheck the selection after a refresh; it can change when the available list changes.

Close or Back before Save abandons the choice. After a request starts, leaving does not undo a possible server update. Reopen this room's settings to inspect an uncertain result.

## Cobelly and invitations

On desktop, Cobelly's selector includes System-type Gear and the supplied System DingDong Gear. Mobile displays Built-in default Gear for Cobelly and disables its dropdown; a private System Gear cannot be selected there.

In mobile invitation setup, Save returns the chosen Gear to the invitation without updating an existing room assignment. Finish Invite to join and equip. If the bot joins but Gear assignment fails, keep the membership and complete setup in that room's DingDong Settings. See [invitation steps](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/dingdongs/invite-to-room.md).

## Completion, limits and recovery

An assignment applies to this DingDong in this room. Other rooms and Flow nodes have their own settings. Gear is ready does not verify devices, browser sign-in, local MCP credentials or successful tool execution. Configure and check those separately.

Reopen from the current account and room if access changes or an old screen closes. After a lost response, inspect the saved assignment before repeating the action.

Also find this under: no Gear, DingDong not ready, assign Gear, equip configuration.
