# Change text size

1. Open Profile → Text size from the desktop avatar/name, mobile Home profile header or More profile card.
2. On desktop, adjust Chat text size. On mobile, adjust App text size, then keep Chat follows app size on or turn it off and adjust Chat text size separately.
3. Choose whether chat inputs should use the chat size.
4. Review the sample message, code and input. Release the slider to save the choice.

The range is 90%–160% in 10-point steps. These are personal preferences for this device, shared across rooms. The preview sends nothing. Reset restores 100% defaults, input scaling on and mobile chat following app size.

No final Save action is required. If saving fails, inspect the error and committed value before adjusting again. Retry reloads a failed settings read.

Lists try to keep the current message visible when text size changes. The visible position can shift as text reflows; scroll to the message you need.
