# Change theme and app colors

Set light/dark appearance and choose or customize a color theme.

## Start here

**Desktop:** Click your avatar/name near the upper-right → Profile → Theme.

**Mobile:** Fifth bottom tab More → profile card → Theme.

## Desktop steps

1. Open Profile → Theme.
2. Choose Light/Dark Mode and Theme Selection.
3. Choose the title-bar style if needed, then close settings. These choices save immediately.

The current desktop theme screen offers default/preset themes and title-bar styles; it has no custom-color editor entry.

## Mobile steps

1. Open More → profile card → Theme.
2. Choose System, Light or Dark.
3. Choose a theme or Custom → Customize Colors.
4. Select a color row, change it and choose Done to put that color into the custom-theme draft.
5. Choose Apply on the whole custom theme to save and activate it. Cancel/Back asks whether to stay or discard a dirty draft.

## Completion, limits and recovery

Brightness and preset selections save immediately. A failed mobile preset save restores the prior theme; a failed custom-theme save keeps the draft for retry. Mobile has no desktop title-bar style setting. For font scaling, use [Text size](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/account/text-size.md).

Also find this under: dark mode, light mode, custom colors, chat color.
