# Request account deletion

Review prerequisites, verify your account and explicitly request deletion.

## Start here

**Desktop:** Click your avatar/name near the upper-right → Profile → Delete Account.

**Mobile:** Fifth bottom tab More → profile card → Delete Account.

## Desktop steps

1. Open Profile → Delete Account and review the prerequisite checks.
2. Cancel active subscriptions and resolve owned group chats if required.
3. Review the warning and verify with the original social account.
4. Enter DELETE and confirm the request.
5. Wait for the result; use Check result if it is uncertain.

## Mobile steps

1. Open Profile → Delete Account.
2. Resolve blockers, including Manage owned group chats.
3. Continue to verification with the original provider/account.
4. Enter DELETE in the final confirmation and request deletion.
5. If status is uncertain, use Check request status.

## Completion, limits and recovery

This signs out all devices and revokes saved payment methods and agent tokens. Recovery is available for 30 days by signing in with the original account. Verification alone does not delete the account. Completed room ownership transfers and room closures are not undone by cancelling account deletion.

Also find this under: remove account, close account, DELETE, recovery period.
