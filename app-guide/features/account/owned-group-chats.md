# Resolve owned chats before deleting an account

Transfer each group’s representative role or close the group before continuing deletion.

## Start here

**Desktop:** Use the owned-room resolution dialog opened by Delete Account.

**Mobile:** Delete Account → Manage owned group chats.

## Desktop steps

1. Start Profile → Delete Account.
2. When owned chats block deletion, open their resolution dialog.
3. Choose a new representative or delete each group.
4. Review and confirm changes, then continue the eligibility check.

## Mobile steps

1. Open Profile → Delete Account → Manage owned group chats.
2. Choose each chat and its transfer or deletion action.
3. Use Review changes and Confirm changes.
4. Refresh until no owned groups remain, then Continue account deletion.

## Completion, limits and recovery

These actions take effect immediately. Closing a group affects every participant. Cancelling account deletion does not reverse transfers or closures. If a result is uncertain, refresh ownership before choosing another action.
