# Check and apply an app update

Follow the current app’s update route when a version is available or required.

## Start here

**Desktop:** Use the optional/required update banner or version information on Profile.

**Mobile:** Fifth bottom tab More → App information, or a required-update screen/banner.

## Desktop steps

1. Read the update banner or Profile version status.
2. Choose Update now.
3. If automatic update fails, use Open download page.
4. Restart when Cobell reports the downloaded update is ready.

## Mobile steps

1. Open More → App information.
2. Choose Check for updates and inspect minimum/latest version.
3. Use Update now when provided.
4. Complete the update through the app’s store/distribution route and reopen Cobell.

## Completion, limits and recovery

Mobile automatic updates are managed in the app store. If version information has not been confirmed, do not claim the app is current. Required updates differ from optional banners and can end an unsupported session. Unpublished feature-enrollment controls are not covered by this guide.

Also find this under: app version, update required, latest version, download page.
