# Review and send diagnostics

Send the app’s offered technical diagnostic report and retain its report ID.

## Start here

**Desktop:** Click your avatar/name near the upper-right → Profile → Send diagnostics.

**Mobile:** Fifth bottom tab More → profile card → Send diagnostics.

## Desktop steps

1. Open Profile → Send diagnostics.
2. Read the technical preview.
3. Use Remove recent errors if desired, then review the refreshed preview.
4. Choose Send reviewed content and retain the returned diagnostic ID.
5. Close the dialog when finished.

## Mobile steps

1. Open Profile → Send diagnostics.
2. Review Information to send.
3. Use Clear recorded errors if needed, then send.
4. Record the Report ID after success.

## Completion, limits and recovery

The mobile preview describes app details and error categories without messages, account details or file contents. Sending is a deliberate user action, not a consequence of merely opening the preview. A submission error does not produce a confirmed report ID.

Also find this under: bug report, diagnostic ID, support information, recorded errors.
