# Report a message

Send the specific message and reason to Cobell, with a separate optional user-block action.

## Start here

**Desktop:** Message More/right-click → Report.

**Mobile:** Message More → Report Message.

## Desktop steps

1. Open the intended message’s Report action.
2. Review its sender/owner and visible content.
3. Choose the reason and optional details.
4. Select the optional block only if intended and submit.
5. Read the report/block result separately.

## Mobile steps

1. Open message More → Report Message.
2. Review Reported message and choose Report reason.
3. Add optional details and decide whether to also block the user/owner.
4. Tap Report and read the result.
5. Resolve blocking prerequisites if the report succeeded but the block did not.

## Completion, limits and recovery

Report and block are separate outcomes. An uncertain submission may already have been accepted; the mobile warning explicitly notes that submitting again can duplicate it. A failed report preserves the draft. Blocking an owner can affect all their DingDongs, not just the reported bot.

Also find this under: spam, abusive message, report owner, report status.
