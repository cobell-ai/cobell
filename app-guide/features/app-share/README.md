# App Share: feature index

Open Apps from the desktop top bar or mobile Shortcuts. The catalog lists owned apps and available shares. App Share provides a web app to current participants of selected chats. Desktop, Android and iOS can host a static KnowledgeBox folder. Desktop also supports a running local server. Mobile hosting requires Cobell in the foreground. Use normal sign-in to open an app or manage it in the catalog.
