# Manage a desktop agent device

Set this desktop's execution permissions after agent sign-in and inspect its local activity.

## Start here

**Desktop:** Complete [agent sign-in](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/authentication/agent-login.md). The restricted screen replaces the personal workspace.

## Steps

1. Check the Agent-Only Login account name and available email. This card does not open Profile.
2. Read any device-settings warning. Use Retry to refresh the current agent device; a displayed initial or retained switch value alone does not confirm the saved value.
3. Set Allow Toolbox on This Device, Allow Access to KnowledgeBox Files on This Device and Share My Device Info as needed. Each change saves immediately. Change one setting at a time and confirm its saved state before changing another.
4. If a save fails, its previous value can return. Use the offered Retry and recheck current settings before repeating a change.
5. Scroll Toolbox executions to read local tool, origin, status, time and duration. These rows and origins do not open details or related conversations. A local storage warning can appear beside available session records; this card has no dedicated Retry.
6. Use the History settings gear for retention or confirmed deletion of completed records. See [history settings](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/security-diagnostics/history-settings.md).
7. Scroll the outer screen to reach Logout when needed. It requests sign-out directly. Shared window controls resize or close the window; window closure is separate from logout.

## Limits

Use your personal session to manage registration, remote agent logout, tokens and Gear targets. The local switches do not make unavailable OS/runtime tools executable.

This desktop screen differs from the [mobile agent dashboard](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/authentication/agent-device.md). It has no matching OS-permission, Screen Use or Sandbox browser control rows. Agent sessions remain excluded from ordinary DingDong OS delivery.
