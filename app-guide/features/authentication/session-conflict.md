# Resolve a login conflict or device limit

Choose how to proceed when Cobell detects another session or too many registered devices.

## Start here

**Desktop:** The relevant recovery dialog appears during sign-in.

**Mobile:** The Already signed in dialog appears during sign-in.

## Desktop steps

1. Review Session Conflict Detected.
2. Choose Logout Other & Login to move the normal session, or the offered Multi-Device Login option.
3. If Device limit reached appears, review the devices and select one to unregister.
4. Use Unregister & Login; after an uncertain result use Retry Same Device.

## Mobile steps

1. Review Already signed in and the device information.
2. Choose Switch to this device, or Sign in as an agent if available.
3. If the registered-device limit is reached, manage devices from a signed-in app and try again.

## Completion, limits and recovery

Normal personal sign-in allows one desktop and one mobile session. Switching replaces a normal session of the same type. The agent alternative is offered only when eligible slots are available.

A device-registration replacement can have completed even if the next login stage fails. Do not choose a different device merely because the result is uncertain. Cancel stops the new attempt; it does not undo a committed device replacement.
