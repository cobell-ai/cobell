# Sign in using another signed-in device

Approve a new device from a Cobell app that is already signed in.

## Start here

**Desktop:** On the new device use Sign in with a verification code; on the approving device use Profile → Approve sign-in with a verification code.

**Mobile:** Use the same two entry points: login verification-code action, and Profile’s approval row.

## Desktop steps

1. On the new device click Sign in with a verification code.
2. Keep its code visible.
3. On an already signed-in app, open Profile → Approve sign-in with a verification code.
4. Enter the code and choose Check device.
5. Review the device, choose Approve login, and wait on the new device.

## Mobile steps

1. On the new device choose Sign in with a verification code.
2. On the signed-in phone, open More → profile card → Approve sign-in with a verification code.
3. Enter the code and tap Check device.
4. Review the requested device and approve or deny.
5. Wait for the new device to complete sign-in.

## Cancel or recover

On the requesting device, Cancel ends the pending login. On the approving device, Deny refuses the request. Desktop Cancel closes the view without approving; mobile Cancel after inspection clears the preview so another code can be entered. Retry reloads failed approval data and never approves by itself.

## Completion, limits and recovery

The code has 10 letters/numbers displayed as two groups of five, such as ABCDE-23456. Copy the displayed code, including letters; the approval input normalizes its separator and case. Normal login permits one desktop and one mobile session; approving another device of the same type signs out the previous normal session. Expired codes require a new attempt on the requesting device. Approve only the login you initiated.
