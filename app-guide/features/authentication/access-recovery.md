# Recover account access and finish sign-out

## Restore a deletion-pending account

1. Sign in with the original Google/Apple account.
2. Read the recovery deadline. While cancellation is offered, choose Cancel deletion and sign in.
3. Wait for restoration. Mobile Continue recovery checks/resumes an existing restoration; desktop can continue its displayed restoration automatically.
4. Confirm that the personal interface opens. If the deadline has expired, read the status; cancellation is unavailable.

Close/Back to login leaves the recovery view without undoing a restoration request already made.

## Finish sign-out

For Saved credentials could not be removed, use Try cleanup again. On mobile, a failed sign-out-finalization screen offers Try again. Keep the app open while these operations progress. New sign-in remains blocked until the required cleanup/finalization succeeds.

Account recovery, local credential cleanup and session finalization are separate operations. Use the recovery action shown for the current state.
