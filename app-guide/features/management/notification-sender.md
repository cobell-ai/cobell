# Configure Notification Sender delivery

Choose room visibility and Desktop/Mobile delivery for a DingDong notification.

## Start here

**Desktop:** Top navigation → Management → Gear → select the Gear → Notification Sender configuration.

**Mobile:** Third bottom tab Shortcuts → DingDong → Gear → select the Gear → Connections → Notification Sender → Built-in configuration.

## Desktop steps

1. Open the Gear’s Notification Sender configuration.
2. Set whether sending is enabled.
3. Choose Desktop and/or Mobile delivery. These are platform types, not individual devices.
4. Set Publish in chat room if a room card is desired.
5. Save and check the target device’s OS-notification setting.

## Mobile steps

1. Open the Gear’s Notification Sender configuration.
2. Set enabled state, delivery device types and Publish in chat room.
3. Save.
4. On each receiving personal device, check OS notifications and system permission.

## Completion, limits and recovery

Notification Sender is automatically included in Gear. Agent-login devices are excluded from ordinary notification delivery. In shared chats, a published notification title/content is visible to participants. A Notification Sender event differs from another Android app’s notification used as a Hook source.

Also find this under: send alert, delivery devices, notification card, Notification Sender.
