# Manage Memory and Toolbox images

Generate and review a private Memory/Toolbox picture before applying it.

## Start here

**Desktop:** Management → Memory or Toolbox → private item → image, or menu → Generate image/Generate new image.

**Mobile:** Shortcuts → DingDong → Memory or Toolbox → private item → Overview → Manage image.

## Desktop steps

1. Open the image action. If a job, candidate or error already exists in the current signed-in session, it reopens that state rather than new options.
2. For a new request, choose one of the six art styles and Next, or Skip (none). In Additional options, optionally pick a local reference and enter a prompt of at most 80 characters. Previous keeps the open draft; Cancel on the style step starts no job.
3. Generate and wait for a candidate. The Current profile preview shows this item's existing picture; it is not an automatically selected reference.
4. Review and Apply to save the candidate. Generate again instead repeats the last inputs; it does not open new settings. Dismissing the candidate does not apply it.
5. Close/dismiss can leave a sent operation running. Reopen the same image/status action to inspect it. Try again retries the failed operation: generation, candidate acceptance or image removal as applicable.
6. To clear an applied picture, use menu → Delete avatar image and confirm Delete. Cancel keeps it. Review the item's saved picture after an uncertain result before repeating removal.

## Mobile steps

1. Open Overview → Manage image. Choose an optional reference, an art style (Cartoon by default) and an optional prompt of at most 80 characters. This form has six styles and no automatic/Skip choice.
2. Generate with the current inputs. Review Generated image separately from Current image. A picked reference alone does not become the applied picture.
3. Use this image saves the candidate, clears the input draft and returns to the detail. If it fails, inspect the retained screen/candidate before generating another image.
4. For Memory generation, Cancel stops that flow. You may leave while generation continues; dirty Back asks to keep/discard the input draft, and discard does not cancel the job. Reopen Manage image to inspect its state.
5. For Toolbox generation, Back is blocked while generating. Applying/removing and reference picking also block departure. After other input edits, Back offers keep editing/discard.
6. When a Memory error offers Retry, it repeats the captured failed generation, acceptance or removal. To change generation inputs, use Generate with the edited fields. Toolbox has no dedicated Retry button: use Generate, a retained candidate's Use this image, or confirmed Remove image as appropriate.
7. Remove image opens its own confirmation and removes the applied picture while keeping the Memory/Toolbox. Remove reference image only clears generation guidance.

## Completion, limits and recovery

References are limited to 10 MiB (10,485,760 bytes). Desktop and mobile Memory accept JPEG/PNG/WebP/GIF; mobile Toolbox accepts JPEG/PNG/WebP. Desktop retries read the same local file again, so it must remain available. A canceled/failed mobile pick retains the previous reference; check which image is still selected before generating, or use Remove reference image.

Only eligible normal signed-in owners can mutate private images. Gear itself has no image generation/Manage image action here. Changing a Memory/Toolbox picture does not change the user profile or every equipped DingDong image. After an uncertain apply/remove result, refresh the item's saved data before repeating the action.

Also find this under: Memory image, Toolbox picture, candidate acceptance, image generation retry, reference image.
