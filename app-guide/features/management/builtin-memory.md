# Inspect built-in Memory missions

View supplied guidance without changing a reusable definition or the Gear that uses it.

## Start here

**Desktop:** Management → Memory → System DingDong mission. The origin filter's Built-in option (B) isolates built-in entries.

**Mobile:** Shortcuts → DingDong → Memory → System DingDong mission. Choose All origins or Built-in if the Private filter hides it.

## Read the mission

1. Open System DingDong mission. The guide explains its role, how System Gear includes it, and what you can ask Cobelly.
2. To try a request, open Start on desktop or Home on mobile and talk to Cobelly.
3. Use Back to leave the read-only guide. Open Gear to inspect a specific Gear's connections.

## Add your own instructions

System-type Gear includes its required System mission automatically and keeps it first. The attachment editor does not let you remove it. Opening the mission detail does not equip Gear or modify an agent.

For extra instructions, [create a private Memory](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/management/memory-create.md), choose compatible supported types, then use [Gear connections and values](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/management/gear-attachments.md) to attach it. This adds your instructions alongside the required mission.

Also find this under: built-in Memory, System mission, automatic instructions, readonly mission, supplied Memory.
