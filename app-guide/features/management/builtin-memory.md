# Inspect built-in Memory missions

View supplied guidance without changing a reusable definition or the Gear that uses it.

## Start here

**Desktop:** Management → Memory → System DingDong mission. The origin filter's Built-in option (B) isolates built-in entries.

**Mobile:** Shortcuts → DingDong → Memory → System DingDong mission. Choose All origins or Built-in if the Private filter hides it.

## Read the mission

1. Open System DingDong mission and read its description and supported type.
2. Inspect desktop Content or mobile Memory prompt. The page displays the current profile name automatically; there is no variable value to enter for the current built-in missions. Mobile's prompt text is selectable. Neither page has a prompt editor or dedicated Copy button.
3. Read Usage on desktop or Gear in use on mobile. For System mission this is a fixed explanation of automatic inclusion, not a fetched list of current Gear references.
4. Use Back to leave. The page has no Save, Rename, Duplicate, image-change or Delete action.

## Add your own instructions

System-type Gear includes its required System mission automatically and keeps it first. The attachment editor does not let you remove it. Opening the mission detail does not equip Gear or modify an agent.

For extra instructions, [create a private Memory](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/management/memory-create.md), choose compatible supported types, then use [Gear connections and values](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/management/gear-attachments.md) to attach it. This adds your instructions alongside the required mission.

## Limits and recovery

Supported-type badges and the built-in badge are readouts, not selection controls. Current missions expose no editable template-variable fields. If the displayed profile name is missing or unexpected, inspect the account profile; this screen cannot change it. Mobile can show a placeholder until the current account's profile is available.

Changing the app language localizes labels, but this screen does not translate the supplied mission text.

Do not look for a usage refresh or recovery write on this page. Open the Gear collection to inspect current connections and their own load/error controls instead.

Also find this under: built-in Memory, System mission, automatic instructions, readonly mission, supplied Memory.
