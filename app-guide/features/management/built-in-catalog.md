# Inspect built-in Toolboxes

Choose a supplied capability and find the Gear settings that actually control it.

## Start here

**Desktop:** Management → Toolbox → B origin filter → select a Toolbox.

**Mobile:** Shortcuts → DingDong → Toolbox → Built-in filter → select a Toolbox.

## Desktop steps

1. Open Management → Toolbox and select a built-in entry.
2. Read the guide for the capability. It describes the Toolbox without checking whether the current device is ready.
3. Where shown, check the usage list for Gear with that capability enabled. Open Management → Gear to change and save the settings.

## Mobile steps

1. Open Shortcuts → DingDong → Toolbox and filter Built-in.
2. Read the guide and, where shown, check Gears using this Toolbox.
3. Open Shortcuts → DingDong → Gear to change and save the Toolbox settings. Use [mobile capture setup](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/devices-browsers/screen-sharing.md) or [Booster setup](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/devices-browsers/android-booster.md) for the corresponding device setup.

## Special catalog pages

Cobell Controller and Notification Sender have no Gear-usage list. Configure notification delivery and select apps for App Management in Gear.

## Completion, limits and recovery

The catalog includes KnowledgeBox Use, Internet Use, Sandbox Browser Use, Screen Use, Mouse Use, Keyboard Use, Cobell Controller, Notification Sender and App Management. Built-ins have no private Rename, Duplicate, image or individual Delete menu. A desktop collection checkbox does not make a built-in removable.

The usage list shows saved Gear connections. Check the chosen device and its permissions before asking a DingDong to use the Toolbox.

Also find this under: built-in tools, capability catalog, Gear usage.
