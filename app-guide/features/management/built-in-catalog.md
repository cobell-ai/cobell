# Inspect built-in Toolboxes

Choose a supplied capability and find the Gear settings that actually control it.

## Start here

**Desktop:** Management → Toolbox → B origin filter → select a Toolbox.

**Mobile:** Shortcuts → DingDong → Toolbox → Built-in filter → select a Toolbox.

## Desktop steps

1. Open Management → Toolbox and select a built-in entry.
2. Read Overview, Support information and the configuration model. Tool descriptions do not run tools, and support labels do not check this device's readiness.
3. KnowledgeBox, Internet, Sandbox Browser, Screen, Mouse and Keyboard pages include Configuration demo. It uses example values. Device/permission/browser choices and Add show a notice; Confirm closes it. Typed text or timeout changes may remain locally, but no Gear settings are saved and no Browser is created.
4. Read Usage for the loaded Gear with that capability enabled. These desktop rows are not links and have no Retry. Return to Management → Gear, open the relevant Gear, then configure and save its actual Toolbox settings.

## Mobile steps

1. Open Shortcuts → DingDong → Toolbox and filter Built-in.
2. Read its capability, support and configuration information. This page has no private Toolbox editing tabs or desktop Configuration demo.
3. For pages with Gears using this Toolbox, tap a row to open actual Gear. A failed catalog read offers a retry row; retained rows during an error are not a complete fresh read.
4. Screen Use's Screen sharing card opens [mobile capture setup](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/devices-browsers/screen-sharing.md). Start sharing and approve the system prompt there; opening the card alone does not start capture. Mouse/Keyboard cards explain desktop-only input control.
5. On supported Android, Sandbox Browser Use → Set up Cobell Mobile Booster opens [Booster setup](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/devices-browsers/android-booster.md). Unsupported devices have no setup button. A connected Booster does not upgrade a Browser session already started in basic mode.

## Special catalog pages

Cobell Controller has no configurable options or demo. It displays capability categories; desktop also explains automatic System Gear attachment. Mobile has no Gear-usage list there.

Notification Sender has no catalog demo or Gear-usage list on either platform. Configure its delivery settings in actual Gear. App Management has selection/monitoring guidance without a desktop demo or usage list; mobile does offer Gear-usage links. Select apps in actual Gear.

## Completion, limits and recovery

The catalog includes KnowledgeBox Use, Internet Use, Sandbox Browser Use, Screen Use, Mouse Use, Keyboard Use, Cobell Controller, Notification Sender and App Management. Built-ins have no private Rename, Duplicate, image or individual Delete menu. A desktop collection checkbox does not make a built-in removable.

There is no final Save on these catalog pages. Usage lists are saved Gear references, not running DingDongs or verified tool execution. Return from demo to the actual Gear settings to make a change. Back does not undo changes saved on a separately opened setup page. Catalog support does not prove this device has the necessary runtime.
