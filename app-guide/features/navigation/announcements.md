# Read announcements

Read published service announcements and distinguish them from DingDong notifications.

## Start here

**Desktop:** Click Start, then Announcement in the empty landing view.

**Mobile:** Home → announcement banner → Details. Home's notifications icon or Announcements button opens the inbox instead.

## Desktop steps

1. Open Start and Announcement.
2. Select the announcement and read its content.
3. Use Try again if the list failed to load, or Close to return.

## Mobile steps

1. In Home, read the banner's title and summary. The body is not a button; choose Details to open its published link in an external application.
2. A successful launch attempts to mark that revision read. If you only want to dismiss it, use the close icon when offered. A notice that disallows dismissal has no close icon.
3. Wait for progress; Details and Dismiss are disabled while the action runs. If opening the link fails, read the launch-failure notice. If saving the read state fails, the notice can return and show Could not dismiss the announcement, even after its link opened.
4. To open the notification inbox instead, use Home's notifications icon or the prompt card's Announcements button. Select an announcement there and return using Back.

## Completion, limits and recovery

A successfully loaded empty list means no announcements were returned for that view. A missing Home banner can also mean notices were read, expired or are still loading.

Read or dismiss the current announcement. Updated notices can appear again. Dismissal does not delete the published notice or guarantee that it is dismissed on another device. If the action fails, wait for progress and retry using the current banner controls.
