# Navigate the main app

Find the main destinations and recognize the different desktop and mobile layouts.

## Start here

**Desktop:** After personal sign-in, use the main window’s top navigation and chat list.

**Mobile:** After personal sign-in, use the five bottom tabs.

## Desktop steps

1. Use Start for Cobelly, or select a room in the chat panel.
2. Use Management for DingDongs, Memory, Toolbox, Gear, Device and Browser.
3. Use Flow or Routine for orchestration and automation. Hover highlights these top-navigation buttons; selected styling marks the current destination.
4. Open Apps from the top bar. Click your avatar or name for Profile, or use the adjacent icons for Multi Chat, Security and Notifications.

## Mobile steps

1. Use Home to find Cobelly, friends and DingDongs.
2. Use Chat for room lists.
3. Use the third tab, Shortcuts, for configuration and Routine. Open **Apps** to find registered or shared apps and **Browser** to manage Sandbox Browsers.
4. Use Flow for orchestration and More for Profile, Security, service status and app information.

Switching mobile tabs restores the destination tab's last location when available. Tapping the current tab opens its starting location. This does not establish that an editor saved its changes. More can show the Security pending-request count or an unavailable exclamation mark. A warning above the tabs opens [Service status](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/security-diagnostics/service-status.md) rather than retrying immediately.

In the fifth tab, More, scroll past the profile card to reach the device OS notification switch, Service status, Screen sharing, Security and App information. Android also offers Cobell Mobile Booster.

The profile card opens Profile. Use Service status for connectivity information, Booster for Android pairing, Screen sharing for its session controls, and App information for version and updates.

The Security shield's number counts pending shell approvals; an exclamation mark means that state could not be obtained. Open [shell approvals](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/security-diagnostics/shell-approval.md) to inspect it. Active timed access is managed there separately. For the More switch's permission and Retry actions, see [OS notifications](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/routines-notifications/os-notifications.md).

## Completion, limits and recovery

Desktop chat panels can be resized by dragging their vertical separators. An unsaved editor may ask you to save or discard before changing destinations. Agent sign-in opens a restricted device-oriented interface rather than the normal personal app.
