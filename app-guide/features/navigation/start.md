# Talk to Cobelly from Start or Home

## Desktop

1. Click Start and type in the central prompt, or use the bottom input of an active Start conversation.
2. Choose Questioner or Decider if needed and wait for the mode to save.
3. Send with the bell or Enter and read the active thread preview.
4. Use Copy or Conceal/Reveal on preview messages as needed. Reply/Edit/Delete in this preview and its attachment-menu choices currently have no implemented action.

On other main pages, the top-bar input sends to Cobelly and opens its chat. A narrow input can collapse into a cobell icon; click it to open the expanded input dialog.

## Mobile

1. Open Home. If needed, open Agent mode and choose Questioner or Decider. Tapping an option attempts to save it immediately; Cancel or dismissal keeps the previous choice. Wait for saving and check any failure notice. A failed initial mode read offers Retry.
2. Enter text in the System DingDong prompt card and use the bell or keyboard Send. Blank text is disabled. While submitting, the input, send button, Announcements and Library are disabled.
3. Continue in the resulting Cobelly thread. The accepted request clears its unchanged draft and dismisses the keyboard. If the message was accepted but the AI request failed, inspect the thread before submitting again. A send failure retains the current draft and shows a notice.

Home also opens Profile, Notifications, Announcements and Library. Its Friends/DingDongs strips provide existing entries, Add and See all; Retry reloads a failed directory.

Tap the Home name/avatar for Profile, or the notification icon for the inbox. An unread badge appears when the count is positive. Announcements in the prompt card opens that same inbox.

Scroll Friends/DingDongs horizontally. Open a friend's profile or a DingDong's conversation. Add Friend opens Send Request; Add DingDong opens Pure creation. See all opens the corresponding full list. Use Retry after a loading error when offered, or reopen the list.

After account or access changes, reopen the current controls. Leaving Home does not cancel a request already sent; check the resulting thread before sending a duplicate.

The Home banner's Details opens an external notice; it does not open the inbox. Use [announcement steps](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/navigation/announcements.md) for its dismissal and save failures. For See all search, pinning and pull-to-refresh, see [full friend/bot lists](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/chat/directory.md).

## Conditions

Cobelly is provided for the account and has no separate KnowledgeBox. Sending a request does not grant device or Toolbox permissions. Use [Library prompts](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/navigation/library.md) for a published starting template.
