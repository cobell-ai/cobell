# View several chats at once

Arrange existing chat rooms in a desktop grid.

## Start here

**Desktop:** Click the grid icon near the upper-right, with tooltip Multi Chat.

**Mobile:** The mobile app opens individual rooms; the desktop Multi Chat grid is not provided.

## Desktop steps

1. Click Multi Chat in the top-right icon group.
2. Choose a layout in the left-side layout controls.
3. Click Select Chat Room in each empty slot.
4. Search or select a category and choose an available room.
5. Use the slot’s Close control to replace its assignment.

## Mobile steps

1. Use Chat to open a room.
2. Return to the list to choose another room; use desktop for a simultaneous grid.

## Completion, limits and recovery

Each slot uses ordinary room controls. Disabled rooms cannot be selected. A slot load error has its own close action.
