# Use Library prompts

## Select and publish

1. Open Start → Library on desktop or Home → Library on mobile.
2. Choose a category and template. Load more or retry a failed read as needed.
3. Read the English title and prompt in the preview. Listing titles can be localized, but direct publication sends this canonical English content.
4. Choose Publish without edits/Publish this prompt, or open Edit and publish/Edit before publishing.
5. For edits, change Title and Prompt, then Publish. The limits are 256 and 65,536 characters; both fields must contain text.
6. Continue the Cobelly conversation after the message is accepted.

## Leave or share

Back, Cancel editing or desktop Esc leaves the current level. Keep editing preserves a dirty draft; Discard abandons it. Copy link shares the published item's location. Recipients still choose whether to publish its prompt.

## Recover

Desktop Check delivery resolves uncertain publication with the original submitted message; editing stays locked until that state is resolved. Avoid creating a new copy while checking it. Mobile can accept the message but report a failed AI request separately; inspect the opened thread before repeating publication.

Publishing sends a Cobelly request. It does not replace the public Library item with your edit.
