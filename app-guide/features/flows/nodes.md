# Configure a Flow task node

## Start here

**Desktop:** Flow editor → Node or select a node.

**Mobile:** Flow editor → Add node or tap a node.

## Configure a task

1. Give the node a name that identifies the work.
2. Select its DingDong and compatible Gear.
3. Enter the prompt and choose an intelligence level.
4. With multiple incoming connections, choose Merge to wait for all paths or Parallel to process paths independently.
5. If this task repeats, enable Self loop and configure iterations, execution mode, concurrency and external propagation.
6. Save/Apply the inspector draft, then Save/Save Flow in the main editor.

## Connect, copy or remove

Use Connect from node or Connect to node to start a connection with this endpoint fixed. On mobile, resolve pending inspector edits first. Duplicate makes another node; Delete removes the selected node. Check affected connections and loops before saving the graph.

## Completion and recovery

Saving a prompt or node inspector does not replace saving the whole graph. Missing assignments can be kept in a saved draft but prevent execution. Open the current graph rather than a recorded execution snapshot to edit a node.

The assignment picker uses DingDong/Gear steps or tabs. No DingDong/No Gear clears the corresponding choice where allowed; it does not delete the DingDong or Gear.
