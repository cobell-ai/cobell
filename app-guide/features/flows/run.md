# Run and control a Flow

## Start a run

1. Apply inspector changes and save the whole Flow.
2. Complete each task's DingDong and Gear assignments and resolve validation issues.
3. Choose Run Flow. On mobile, press the cobell/run button in the run sheet to submit the request.
4. Watch the execution banner and node statuses.

## Pause, resume or stop

Use Interrupt to pause active work. Resume opens the resumption controls and accepts optional guidance. Use Terminate/stop when the run should end. If requests are queued, open the queue badge to review or cancel pending requests.

## Inspect results and return to editing

Select a node to read its outcome or open Notices for execution observations. Wait for final-report writing when it is still in progress. After the run ends, Clear display returns to the editable current graph and preserves history.

## Completion and recovery

Read the recorded state rather than treating a button press as completion. Retry a failed state read. Connection loss does not establish that the server stopped execution. If final-report writing fails, inspect the node outcomes and notices to determine what work finished.
