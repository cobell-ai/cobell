# Change a Flow image

## Generate and apply

1. Open the Flow list. On desktop, click its image or use the row's image menu; on mobile, choose Flow image from the row menu.
2. Choose an art style and optional reference image/prompt. Desktop also lets you skip style selection. Prompts accept up to 80 characters.
3. Choose Generate and wait for a candidate.
4. Review the candidate. Apply/Use this image saves it to the Flow. Generate/Regenerate requests another result.

## Cancel or reopen

Mobile offers Cancel generation while generation is pending. Desktop's progress dialog offers Close; reopen the image/status surface to inspect the job or candidate. Closing a view does not apply an unaccepted image.

## Remove or recover

Use Remove image/Clear and confirm to remove the applied Flow image. Removing an optional reference only clears generation guidance.

Use Retry for a failed operation when offered. Mobile reference images accept JPEG, PNG, WebP or GIF within 10 MiB. If the picker reports permission or file errors, resolve them and select a supported reference again.

Image operations leave the graph unchanged. Wait for applying/removal to succeed before treating the Flow image as updated.
