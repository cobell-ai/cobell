# Create and maintain a Flow

## Start here

**Desktop:** Flow → Add.

**Mobile:** Flow → Create Flow.

## Create

1. Enter a name and description. Describe the input, intended work and expected result.
2. Complete creation and open the editor.
3. Add task nodes, assign their DingDongs and Gear, and connect them.
4. Save the graph before running it.

## Maintain the catalog

Use Sort or Refresh to find an entry. Open its name, description or avatar actions to change its identity. Duplicate creates a separate Flow. Open Execution history to inspect recorded runs.

For reference images, generation, candidate application and removal, see [Change a Flow image](https://raw.githubusercontent.com/cobell-ai/cobell/main/app-guide/features/flows/image.md).

For bulk removal, enter Edit/Select mode, select entries and confirm deletion. For one entry, use its Delete action. Deleting a Flow also removes its associated chat; clearing its graph is a different operation.

## Completion and recovery

Wait for creation or metadata saving to succeed. Opening the mobile Run Flow sheet does not start work. Use Retry after a failed catalog load and review deletion errors before repeating a removal.
