# Validate and save a Flow

## Save an edited graph

1. Apply any node, connection or loop inspector draft.
2. Choose Save on desktop or Save Flow on mobile.
3. Resolve reported structural issues and save again.
4. Wait for saving to finish before leaving or running.

## Check execution readiness

On mobile, open Validate flow to inspect issues. Before execution, every task must have its DingDong and compatible Gear. A graph can be structurally valid and saved while these assignments are incomplete.

Check required browser sessions, files and connected devices separately. Graph validation cannot establish that those resources will be available when a task uses them.

## Leave or recover

Mobile offers Stay, Discard or Save when leaving with changes. Restore saved Flow replaces the draft after confirmation. If saving fails, the draft remains available for retry; review the error before assuming the server has the new graph. Retry a failed load before making further changes.
