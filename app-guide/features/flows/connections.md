# Connect Flow nodes and choose data propagation

## Start here

**Desktop:** Flow editor → Conn.

**Mobile:** Flow editor → Add connection.

## Connect two tasks

1. Select a source node and a different target node. Starting with Connect from/to node preselects one endpoint.
2. Choose Previous result when the target needs the source's output. Choose Dependency only when only execution order matters.
3. Create or apply the connection.
4. Save the whole Flow.

## Change or remove a connection

Select the connection to change propagation, switch direction or delete it. Review any confirmation concerning an existing opposite connection. If a loop protects the connection, change or remove that loop before changing the path.

## Completion and recovery

Cancel exits unfinished connection creation. Resolve validation errors rather than repeatedly adding the same connection. A graph layout direction change does not substitute for choosing the intended source and target.
