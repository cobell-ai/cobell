# Read Flow execution history and notices

## Inspect a past run

1. Open Execution history for the Flow from its row/menu or editor.
2. Select a run using its time, status and trigger origin.
3. Read its final output/report state and individual node outcomes.
4. On mobile, open Nodes, Connections, Loops or Events to inspect that run's saved execution snapshot.
5. Request older records as needed.

## Read observations

Open Notices from a displayed run or node to read observations for that scope. Use Load more for older observations and Retry after a failed read. On desktop, the new-observations control returns to the live end when you have scrolled away.

## Completion and recovery

Read node outcomes when the final report is absent or failed. To change the Flow, leave history and open the current graph. For an ended run still displayed in the editor, Clear display returns to editing without deleting the run record.
