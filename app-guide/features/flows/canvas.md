# Navigate and edit the Flow canvas

## Start here

**Desktop:** Flow → open the editor.

**Mobile:** Flow → open the editor → Canvas tools.

## Arrange the graph

1. Pan and zoom to the relevant nodes. Use Center canvas on mobile if the graph is out of view.
2. Drag a desktop node, or long-press and drag a mobile node.
3. Select a node, connection or loop to open its controls.
4. Apply any inspector changes, then choose Save/Save Flow in the main editor.

## Change layout or clear the graph

On desktop, drag the inspector's upper boundary up or down to resize it within the available window space. Resizing changes the panel, not the graph, and needs no graph Save. It is also available in read-only views where the inspector is shown.

Use Dir/Flow direction for graph direction settings. Mobile Canvas tools also offers horizontal and vertical arrangements. These edits remain part of the unsaved graph draft.

Clear/Clear all nodes asks for confirmation and removes the graph's nodes, connections and loops. Use it only when rebuilding the graph. It does not delete the Flow.

## Completion and recovery

Wait for Save Flow to succeed before leaving. Mobile Restore saved Flow discards the draft after confirmation. If a completed run is still displayed, Clear display returns to the current editable graph; it does not clear graph content or delete history.
